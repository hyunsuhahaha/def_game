# 프런트엔드 UI 아트 디렉션 v2

## 품질 기준

레벨업 3택 화면은 이 프로젝트의 품질 기준이 아니다. 프런트엔드 전체는 유명 상업 인디게임에서 확인되는 다음 완성도를 기준으로 한다.

- **Hades:** 한 화면에 하나의 결정을 강하게 부각하는 정보 위계와 즉각적인 입력 피드백
- **Cult of the Lamb:** 게임 세계관과 메뉴 장식이 분리되지 않는 일관된 아트 디렉션
- **Balatro:** 작은 상태 변화도 색·움직임·소리로 읽히는 반응성과 명확한 선택 상태
- **Dave the Diver:** 콘텐츠 진입 전 기대감을 만드는 브리핑, 전환, 보상 예고

정확한 레이아웃이나 자산을 복제하지 않는다. 위 원칙을 이 게임의 **불법 산림개발 회사 지휘실, 현장 명령서, 경고 장비**라는 시각 언어로 번역한다.

## 공통 표현 규격

1. 화면마다 가장 중요한 행동은 하나만 주황색 실체 버튼으로 표시한다.
2. 패널은 단색 사각형 한 장으로 끝내지 않는다. 그림자, 외곽 림, 상단 반사선, 좌측 상태 레일, 모서리 장치를 겹친다.
3. 영문 마이크로 라벨은 시스템 계층을, 한국어 제목은 실제 결정을 설명한다.
4. 선택 항목은 밝기 변화만 주지 않는다. 3~5px 상태 레일, 테두리, 텍스트 대비가 함께 바뀐다.
5. 버튼은 hover 시 3px 상승하고 외곽 대비가 증가한다. 키보드 입력 표시는 별도 키캡으로 둔다.
6. 1280×720을 주 화면으로 사용하되 960×540에서도 정보가 겹치거나 화면 밖으로 잘리지 않아야 한다.
7. 화면 역할에 따라 실제 게임 아트 또는 반응형 UI를 사용한다. 현재 활성 로비는 고정 배경 이미지 없이 저대비 픽셀 작업면을 쓴다.
8. 메뉴 문구는 기능·대상·수치만 짧게 말한다. 분위기를 만들기 위한 명령문, 광고 문구, 과장된 세계관 설명을 쓰지 않는다. `온대림 1구역`, `할당량 60그루`, `작업 준비`처럼 구체적으로 쓴다.

현재 활성 로비는 배경 그림 한 장에 메뉴를 얹지 않는다. `게임 시작·강화·연습·업적·설정`만 세로 메뉴로 두고, 선택 상태는 픽셀 레일과 한 단계의 색 변화로만 표시한다. 관제 패널·상태 카드·진단 탭 같은 장식성 정보 구조는 사용하지 않는다. 배경은 화면 크기에 맞춰 새벽 하늘·태양·먼 능선·숲 가장자리·풀밭 공터의 깊이를 다시 계산하고, 승인된 v3 나무·숲 소품·바닥 데칼을 실제 팔레트로 배치한다. 원경과 전경은 마우스 위치에 따라 약하게 어긋나고 나무는 1~2픽셀만 흔들린다. 로비 배경에 작업자 캐릭터를 세우지 않으며, 왼쪽 메뉴 영역은 비우고 오른쪽 전경에 무게를 둔다. 이전 배경 화면의 왼쪽 아래 오디오 바 감각은 작은 픽셀 플레이어로 보존하며, 이전/재생·정지/다음과 `R`, `[`, `]` 단축키를 지원한다. 보존된 캠페인용 배경 자산은 삭제하지 않는다.

로비 전용 타이포그래피는 `assets/font-korean-pixel.ttf`의 Neo둥근모 Pro를 정수 크기로 사용한다. 제목·메뉴·키캡·오디오 트랙명을 같은 픽셀 계열로 묶고, 선택 항목은 블록 커서와 잘린 모서리의 2픽셀 프레임으로 구분한다. Noto Sans KR 기본 고딕과 둥근 웹 카드형 메뉴는 로비에 사용하지 않는다.

## 화면 흐름

`지휘실 → 작업자 편성 → 생태 구역 선택 → 현장 투입 브리핑 → 플레이`

위 흐름은 보존된 캠페인 설계다. 현재 프로덕션 로비의 활성 개발 경로는 **흡연자 벌목 기록 모드 → 기록전 영구 연구 → 플레이**뿐이다. 캠페인, 다른 작업자, 지구본, 브리핑, 보스전과 러시는 삭제하지 않고 의도적으로 진입만 막아 두었다. 다른 작업자가 이를 미완성 코드로 오인해 삭제하거나 로비에 다시 노출하지 않도록 [활성 개발 모드](ACTIVE_DEVELOPMENT_MODE.md)를 기준으로 삼는다.

지구본의 지역 표식을 클릭하면 해당 지역을 선택하고 브리핑으로 이동하지만 게임을 즉시 시작하지는 않는다. 브리핑에서 작업자·구역·초기 단계가 함께 확인된 뒤 최종 승인해야 게임 시간이 진행된다. 숫자키로 지역에 초점을 맞춘 경우에는 `선택 지역으로 이동` 버튼 또는 Enter로 브리핑에 들어간다.

## 화면별 역할

- **지휘실:** 현재 작전 상태와 단 하나의 주 CTA를 보여준다. 도감·특성·설정은 상단 유틸리티 내비게이션이다.
- **작업자 편성:** 한 명의 대형 인사 기록과 우측 인원 명부를 함께 사용한다. 여섯 장의 동일 카드 나열을 금지한다.
- **생태 구역:** Natural Earth 1:50m의 실제 육지·섬·호수 윤곽을 1024×512 카툰 픽셀 지도로 제작해 구면 셰이더로 투영한다. 마우스 드래그로 경도 360° 회전하며 관성이 남고, 휠로 70~115% 확대·축소한다. 위도는 극점 전복을 막는 범위 안에서 기울인다. 지역 표식은 실제 위·경도에서 앞면으로 투영된 경우에만 입력을 받는다. 표식 hover 시 오른쪽 패널의 현장 프리뷰·수목·단계·완료 상태가 바뀌고 클릭하면 브리핑으로 이동한다. 클리어 지역은 초록 이중 링과 체크 배지를 항상 표시한다.

지리 원본은 `assets/ui/sources/ne_50m_land.geojson`, `ne_50m_lakes.geojson`에 보존한다. [Natural Earth 1:50m physical vectors](https://www.naturalearthdata.com/downloads/50m-physical-vectors/)를 사용했으며 [이용 조건](https://www.naturalearthdata.com/about/terms-of-use/)에 따라 공개 도메인이다. 실제 해안선은 유지하고 색·명암·산맥 표시는 게임용 카툰 픽셀 표현이다.
- **브리핑:** 선택 결과를 최종 검토하는 작전 명령서다. 승인 전에는 런을 생성하지 않는다.
- **환경 설정:** 실제 설정과 개발자 도구를 다른 섹션으로 분리한다. 설정값은 토글 상태로 즉시 읽혀야 한다.
- **개발자 도구:** 로비에서는 다음 런 시작 레벨 `+20`을 한 번 예약하고, 진행 중에는 현재 런 레벨 `+10`을 지급한다. 일반 방어·러시·벌목 런의 각 레벨/3택 큐에 맞게 적용하며, 다음 런 예약은 한 번 소비한 뒤 즉시 지운다. 자원 예약·영구 재화·2회 확인 초기화도 같은 검증 범위에 둔다.
- **특성 연구:** 캐릭터 기록, 연구망, 미니맵을 하나의 연구 시스템처럼 보이게 유지한다.
- **레벨업 선택:** 기존 3택을 기준으로 삼지 않고 공통 배경·계층 라벨·입력 반응을 적용한다. 카드 내부 정보보다 선택의 중요도와 희귀도 연출이 먼저 읽혀야 한다.

## 특성 연구망 v2 규격

- 배경은 저채도 갈색이나 회색 워시가 아니라 짙은 남색 연구 공간으로 둔다. 노드 내부는 거의 검정에 가깝게 눌러 아이콘과 외곽광이 먼저 읽히게 한다.
- 노드는 원형 점 대신 큰 마름모 프레임을 쓴다. 해금 가능은 직업색 외곽광과 초록 `+`, 활성은 밝은 진행 링, 잠금 경로는 선명한 마젠타 적색으로 상태를 동시에 구분한다.
- 연결선은 넓은 반투명 글로우, 2~4px 색 코어, 얇은 흰 반사선의 3단 구조다. 활성 경로에는 작은 광점이 이동한다.
- 기본 배율 `.62`, 허용 배율 `.36~1.60`, 휠 1단계 배율 `1.22`다. 좌·우 버튼 드래그를 모두 받고 놓은 뒤 관성 감쇠를 적용한다. 미니맵 클릭은 즉시 이동하며 관성을 취소한다.
- 1280×720에서는 기록 패널과 첫 분기 전체가 함께 읽혀야 한다. 960×540에서는 초상 비율을 낮춰 설명과 상세 카드가 겹치지 않아야 한다.
- 실제 검수본은 `trait-research-v2-1280.png`, `trait-research-v2-960.png`이며 이전 `frontend-v2-traits.png`의 저채도 원형 노드 화면을 새 작업 기준으로 사용하지 않는다.

# 3택 카드 반응형 가독성 규격 (v3)

- 세 카드 묶음은 해상도와 관계없이 가로 중앙에 놓고, 제목 아래부터 하단 조작부 위까지의 실제 가용 높이 안에서도 세로 중앙에 놓는다.
- 1920×1080 이상에서는 기존 300×430 고정 크기에 머물지 않고 카드 폭 최대 350, 높이 최대 500까지 확장한다.
- 960×540은 1280×720 가상 레이아웃을 축소해 카드 순서·클릭 판정·여백 비율을 보존한다.
- 카드 설명은 전체 기획 문장을 그대로 밀어 넣지 않는다. 선택에 필요한 핵심 작동을 별도 요약하고, 남은 높이에 따라 본문·작은 본문·마이크로 글꼴 중 가장 큰 글꼴을 자동 선택한다.
- 카드 이름, 트랙, 핵심 효과, 다음 레벨은 구분선으로 분리한다. 설명과 하단 레벨 영역은 어떤 길이에서도 겹치지 않는다.
- 리롤·배니시 버튼과 융합 진행판은 화면 하단을 기준으로 배치하며 고정 `y=608` 좌표를 사용하지 않는다.
- 모든 일반 카드에 식별 아이콘이 있어야 한다. 비어 있던 `마른 건초더미 생성`은 전용 건초 픽셀 아이콘을 사용한다.
- 검수 화면: `previews/levelup-responsive-v3-1920.png`, `levelup-responsive-v3-1280.png`, `levelup-responsive-v3-960.png`.
