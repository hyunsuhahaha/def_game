# 마른 건초더미 생성 — 판정과 전용 픽셀 그래픽

## 판정

1. 건초더미 위 약 70~90px 이내에 담배꽁초가 착지하면 예열 상태가 고정된다. 시각 크기와 함께 판정도 커진다.
2. 0.5초 동안 꽁초·검댕·붉은 짚 끝이 단계적으로 표시된다.
3. 정확히 0.5초 뒤 건초더미 자체에 불이 붙는다.
4. 6초 동안 0.4초마다 지속 피해를 준다. 반경은 1레벨 약 107에서 6레벨 160, 피해는 약 4.15에서 8까지 성장한다.
5. 건초더미 화염은 나무나 다른 건초더미로 번지지 않는다. 타는 나무 근처에 있다는 이유로 점화되지도 않는다.

## 시각 방향

건초더미 본체는 기존 0.60배에서 0.88배로 키웠다. 연소 중에도 금빛 형태와 밧줄이 유지되며 재나 검은 덩어리로 변하지 않는다.

불꽃은 더 이상 여섯 프레임을 교체하지 않는다. `straw-bale-fire.glsl`이 고정된 원생 픽셀 격자에서 여러 불꽃 혀의 높이·폭·휘어짐·내부 하이라이트·불티를 연속 시간으로 계산한다. 픽셀 셀과 제한 팔레트는 유지하지만 시간값을 프레임 단위로 양자화하지 않아 60fps에서 매 프레임 부드럽게 변한다. 어두운 적갈색 외곽 → 구리색 → 호박색 → 꿀빛 → 크림색 심지의 재질 램프로 기존의 과도한 순수 노랑·주황 대비도 줄였다.

발화 중에는 실제 피해 반경과 같은 납작한 열기 타원이 바닥에 표시되어 공격 범위를 바로 읽을 수 있다. 이는 입체 모델을 사용하는 진짜 3D 렌더는 아니지만, 연속 변형과 움직이는 명암 때문에 2D 픽셀 불꽃보다 체적감 있게 보인다.
