# 마른 건초더미 생성 — 판정과 전용 픽셀 그래픽

## 판정

1. 건초더미 위 약 112~150px 이내에 담배꽁초가 착지하면 예열 상태가 고정된다. 시각 크기와 함께 판정도 커진다.
2. 0.5초 동안 꽁초·검댕·붉은 짚 끝이 단계적으로 표시된다.
3. 정확히 0.5초 뒤 건초더미 자체에 불이 붙는다.
4. 6~12초 동안 0.4초마다 지속 피해를 준다. 반경은 1레벨 약 153에서 6레벨 220, 피해는 약 7.2에서 13까지 성장한다. 반경 안의 나무도 불씨 전이 없이 같은 직접 피해를 받는다.
5. 건초더미 화염은 나무나 다른 건초더미로 번지지 않는다. 타는 나무 근처에 있다는 이유로 점화되지도 않는다.

## 시각 방향

건초더미 본체는 320×288 원생 픽셀 자산을 0.55배로 표시해 기존보다 훨씬 크게 만들었다. 긴 면은 화면 가로축과 평행하고 좌우 끝과 결박 끈은 수직인 직선형 실루엣을 사용한다. 사선 회전이나 비스듬한 바닥 면은 금지한다. 연소 중에도 금빛 형태와 밧줄이 유지되며 재나 검은 덩어리로 변하지 않는다.

불꽃은 사용자 선택 A 시안을 8프레임 투명 아틀라스로 베이크해 초당 12프레임으로 반복한다. 흰 고온층은 바닥에서 이어지고, 붉은·주황 불꽃 끝은 프레임마다 솟고 갈라지고 꺼진다. 1픽셀 불티와 별도로 5~16px 크기의 끊어진 불꽃 덩어리 세 묶음이 서로 다른 시점에 상승·분열·소멸한다. 같은 루프를 앞뒤 깊이에 3프레임 차이로 배치해 한 줄이 통째로 같은 방향으로 움직이지 않는다.

발화 중에는 실제 피해 반경과 같은 납작한 열기 타원이 바닥에 표시되어 공격 범위를 바로 읽을 수 있다. 이는 입체 모델을 사용하는 진짜 3D 렌더는 아니지만, 연속 변형과 움직이는 명암 때문에 2D 픽셀 불꽃보다 체적감 있게 보인다.
