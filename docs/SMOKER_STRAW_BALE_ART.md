# 마른 건초더미 생성 — 판정과 전용 픽셀 그래픽

## 판정

1. 건초더미 위 48px 이내에 담배꽁초가 착지하면 예열 상태가 고정된다.
2. 0.5초 동안 꽁초·검댕·붉은 짚 끝이 단계적으로 표시된다.
3. 정확히 0.5초 뒤 건초더미 자체에 불이 붙는다.
4. 6초 동안 반경 60에 0.4초마다 4의 지속 피해를 준다.
5. 건초더미 화염은 나무나 다른 건초더미로 번지지 않는다. 타는 나무 근처에 있다는 이유로 점화되지도 않는다.

## 시각 방향

건초더미는 연소 중에도 금빛 형태와 밧줄이 유지된다. 재나 검은 덩어리로 변하지 않는다. 불꽃만 좌우 휘어짐, 세로 신장, 낮은 압축, 분열, 회복의 여섯 프레임을 반복한다. 반실사 초안과 탄화되는 카툰 초안도 삭제하지 않고 `concepts`에 보존했다.
