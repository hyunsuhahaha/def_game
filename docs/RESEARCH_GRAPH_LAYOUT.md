# 연구 그래프 보수적 재배치 — 2026-09-08

기존 그래프·아이콘·연결선·휠 확대/축소·드래그를 유지한다. 카드 목록이나 갈래별
별도 화면으로 교체하지 않는다. 축소 화면에서 이름을 생략하는 기존 동작도 유지한다.

## 변경 경계

- 흡연자 101노드·339랭크, 가격, 선행 조건, 구매 순서, 효과, 저장 형식은 그대로다.
- 공간·이동의 노드 수와 효과도 유지하며 겹치는 위치만 옮긴다.
- 대시와 두더지, 두 작업 구역, 시야와 수용량, 산불과 기름통 등 좁은 구간을 벌린다.
- 로봇 해금은 루트에서 약 854, 두더지는 약 1209, 기름통은 약 1331 월드 거리다.
  초반 해금은 안쪽에, 후속 강화는 기존 방향으로 바깥에 둔다.
- 모든 노드 중심 간격은 최소 230이다. 108개 선행 연결은 전부 유지한다.
  다른 노드의 중심 ±90 사각 영역을 관통하던 19개만 최단 가시 경로로 우회한다.
  선끼리의 교차가 모두 제거되었다는 뜻은 아니다.
- 경로는 월드 좌표로 캐시한다. 확대·축소·드래그나 구매로 다시 계산하지 않는다.
  기존 활성 연결선의 이동 불빛도 우회 경로를 따른다. 건설업자 배치는 바꾸지 않는다.

## 성장 피드백

합쳐진 다중 효과 연구는 `rankEffects[level+1]`에서 다음 효과를 직접 읽는다.
단순히 전체 설명만 반복하지 않고 이번 구매의 효과와 해당 연구의 누적 전후 수치를
표시하며, 자동 투척 간격과 고양이 확률은 실제 계산식·상한을 반영한다.
구매 직후에도 같은 효과를 확인 메시지로 남긴다. 최종 잡 마스터 안내는 덮지 않는다.

확인한 로컬 플레이 기록의 2026-09-08 초반 1단계 5판 수입은 48~66코인이다.
이 자료만으로 모든 구간의 구매 빈도를 보장할 수 없으므로 가격·정산 배율을 추가로
변경하지 않았다. 저장된 효과 순서를 바꾸거나 기존 구매를 재배분하지 않는다.
이번 변경은 성장 수치 재조정이 아닌 탐색 동선과 구매 효과 전달 개선이다.

## 검증

- `scripts/verify_research_layout.lua`: 전체 노드 간격, 전체 연결의 타 노드 관통,
  경로 캐시, 초반 자동화 거리, 혼합 효과 전 단계 설명, 저장 불변.
- `scripts/verify_character_traits.lua`: 기존 그래프 클릭/구매/줌/드래그 및 저장 회귀.
- `scripts/render_score_trait_board.py`: 실제 Lua draw 경로의 오프스크린 기본·축소·
  넓은 화면·두더지·기름통·화염·작은 화면·구매 완료 검수. 게임 창은 실행하지 않는다.

새 자산·애니메이션·셰이더·판정 변경은 없으므로 자산 제작 항목은 해당하지 않는다.

최종 전체 헤드리스 검사: 98개 통과, 기존 실패 2개. `verify_lakeside.lua:36`의
확장 필드 경계 검사와 `verify_documentation_sync.lua:17`의 세계수 종료 문구
검사가 실패한다. 해당 코드·검사와 활성 모드 문서는 이번 작업에서 수정하지 않았다.
연구판·구매·저장·기록부 관련 검사는 모두 통과했다.
