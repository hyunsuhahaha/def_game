# F안 — 밝은 호숫가 기록전 (재생 1~10단계)

사용자가 고른 [밝은 F안](../assets/scenery/lakeside/approved-light-f-concept-v1.png)을 기록전 숲의 고정 외곽 풍경으로 연결했다. 산·단차 프로토타입은 복원된 상태이며, 플레이 지면과 전투는 기존 평면 좌표계를 유지한다. 1~5단계는 별개 배경 5종이 아니라 **한 호숫가에서 내륙으로 확장되는 다섯 재생 단계**다. 보존된 캠페인·다른 바이옴은 바꾸지 않는다.

이 배경은 재생 10단계까지만 사용한다. 11단계부터는 물이 없는 [밝은 작업 고원](UPLAND_FIELD.md)으로 전환한다.

## 좌표와 확장

`src/lakeside.lua`가 확장 경계를 계산하고 `Maps.configureScoreTier`에서 숲에만 적용한다. 월드 크기 W/H와 배경의 월드 좌표는 재생 단계 동안 고정이다.

| 단계 | 열린 폭 / W | 열린 높이 / H |
|---|---:|---:|
| 1 | .7500 | .7000 |
| 2 | .7875 | .7375 |
| 3 | .8250 | .7750 |
| 4 | .8625 | .8125 |
| 5 | .9000 | .8500 |

오른쪽 끝은 항상 `.93W`, 아래쪽 끝은 `.88H`다. 따라서 왼쪽·위쪽만 열린다. 6단계 이후에도 남은 폭/높이 `.03W/.03H`의 18%씩 열어 기존 고단계 저장을 지원한다. 최대 경계는 x/y=0에 접근하지만 바깥으로 넘어가지 않는다. `작업 구역 확장` 연구의 월드 배율·허용량 효과는 그대로 유지한다.

스폰·이동·자재 경계는 기존 `playBounds` 판정을 공유하므로 물이나 미개방 구역으로 이동하지 못한다. 배경의 호수는 시각 전용이며 수영·배·별도 물리 시뮬레이션은 없다. 해안선을 따라 움직이는 다각형 충돌이 아니라 해안 안쪽의 안전한 플레이 경계를 사용한다.

닫힌 구역은 **낮은 풀과 작은 바위**를 드문드문 배치해 표시한다. 실제 벌목 나무와 동일한 스프라이트를 쓴 장식 군락은 초반 목표와 혼동되어 v2에서 제거했다. 경계 소품은 폭 최대 65월드 단위 이하이며 전투 나무/허용량/벌목 목표에 포함하지 않는다. 먼 배경 숲만 대비를 낮추고 플레이 지면·실제 나무·호수 색은 유지한다. 고정 시드로 배치한 경계 소품은 구역 개방 시 1.35초 동안 사라진다. 기존 전투 나무와 점수는 유지한다. 크레인 전경은 약 1.35초에 걸쳐 새 구역과 호수가 보이도록 넓어진다. 기존 사람 시점·원근 기울기·조준 역투영은 그대로다.

## 아트와 실제 연결

- `assets/scenery/lakeside/lakeside-environment-pixel-v1.png`: 깨끗한 환경 플레이트. 실제 플레이어·크레인·불·나무 전투 객체는 여기에 구워 넣지 않는다.
- `assets/shaders/lakeside-ground.glsl`: 고정 월드→배경 UV 매핑, 호수 바깥 수면의 작은 물결. 경계 밖은 주변 재질을 반사 반복해 검은 여백/끝 픽셀 늘어짐을 피한다. 일반 가로 화면 카메라는 가능한 한 원본 풍경 안쪽을 사용한다. 극단적인 창 비율에서는 외곽 반복이 보일 수 있다.
- `src/world.lua`: 지면 패스와 기존 빌보드 큐에 연결. 낡은 북쪽 원경/바닥 자르기를 숲 기록전에서만 제외한다.
- `src/camera.lua`: 호수 쪽 여백을 포함하는 크레인 전경, 구역 개방 중 완만한 이동/축소.

내장 ImageGen으로 F-light를 편집했다. 최종 요청은 “기존 올리브/세이지 카툰 픽셀 호숫가를 유지하고 HUD·사람·크레인·관·불·전투 나무·잔해를 모두 제거. 오른쪽/아래쪽 호수와 자연 해안선, 바깥 혼합 숲을 유지. 중앙/왼쪽은 장애물 없는 평탄한 풀밭. 검은 여백·지평선·실사화·전역 어두운 필터 금지”다. 생성 원본은 기본 생성 폴더에 보존하고 프로젝트에는 버전 파일로 복사했다. 기존 자산을 덮어쓰지 않았다. 환경 플레이트는 현재 출력 픽셀 그리드로 nearest 로딩한다.

## 검증

전체 테스트는 사용자의 비용 요청에 따라 실행하지 않았다. 게임 창도 띄우지 않았다.

```powershell
python scripts/headless_lua.py scripts/verify_lakeside.lua scripts/verify_crane_attack_feel.lua
python scripts/render_lakeside.py
python scripts/render_crane_full_scene.py
python scripts/verify_asset_versions.py
git diff --check
```

확장 방향·고정 해안측 경계·미개방 이동 차단·조준 왕복·카메라 프레이밍·개방 애니메이션 종료·다른 지역 분리를 검사한다. 기존 잡 마스터/화염방사기/동료와 크레인 공격 회귀도 포함한다. 실제 `Game.draw` 명령과 GLSL을 창 없는 GPU 재생기로 렌더했다. 이는 엔진 실행 캡처가 아니라 실제 게임 드로우 기반 오프스크린 렌더다.

v2 실제 표시 크기: [초반 튜토리얼](previews/lakeside-tutorial-v2.png), [1단계 전경](previews/lakeside-stage-1-v2.png), [픽셀 확대](previews/lakeside-pixel-inspection-v2.png). 튜토리얼은 실제 한 그루 목표와 사람 카메라를 사용하며 검수용 나무를 추가하지 않는다. 단계별 전경만 실제 식재 함수로 35그루를 추가하고 출현을 완료한 뒤 촬영한다. 게임의 시작 6그루 설정은 바꾸지 않는다. 경계 큐에 벌목 나무 파일이 들어가면 실패하는 회귀 검사도 추가했다. 이전 v1 미리보기는 이력으로 보존한다.
