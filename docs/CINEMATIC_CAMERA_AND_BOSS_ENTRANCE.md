# 2.5D 카메라와 보스 등장 연출

**상태: 2026-08-28 런타임 연결 및 오프스크린 검수 완료.** 전투 화면은 지면, 깊이 정렬된 플레이 공간, 화면 가장자리 전경 수관의 세 평면으로 나뉜다. 이동과 돌진의 반대 방향으로 전경이 더 늦게 따라오고, 월드에는 최대 약 1°의 짧은 롤과 줌 충격이 들어간다. 마우스 월드 좌표는 회전·줌의 역행렬을 사용하므로 연출 때문에 조준점이 어긋나지 않는다.

## 카메라 원칙

- 평상시에는 관성·롤을 작게 유지해 고정 픽셀 그리드와 판독성을 보존한다.
- 중장비 돌진과 보스 착지에만 방향성 임펄스, 짧은 줌 펀치, 감쇠 롤을 준다.
- 전경 수관은 현재 맵의 실제 나무 이미지를 사용하며 화면 하단 가장자리에서만 보인다. 별도 실사 이미지나 흐린 가짜 심도 레이어를 사용하지 않는다.
- 보스 연출 동안 카메라는 플레이어와 보스 사이를 잡고, 종료 후 자연스럽게 플레이어에게 돌아온다.
- 일반 전투에서도 이동 판정은 `playBounds`에 유지하되 카메라는 북쪽으로 900 월드 단위 더 열린다. 플레이 지면은 북쪽 수풀·바위 능선에서 끝나고, 그 너머에는 충돌하지 않는 지역별 계곡·습지·고원·해양 파노라마가 드러난다. 좌우·남쪽 경계와 충돌 범위는 바뀌지 않는다.
- `screenToWorld`는 렌더 위치, 렌더 줌, 롤을 모두 역변환한다.

## 맵별 보스 등장

등장 중 약 2.5~2.75초 동안 플레이어, 일반 적, 투사체, 보스 AI와 피격 갱신을 멈춘다. 지역 야생동물과 전용 등장 FX는 계속 움직인다. 보스 이름 카드나 `등장!` 문구는 띄우지 않으며, 충격 시점부터 얇은 붉은 픽셀 체력 바만 펼쳐진다.

| 맵 | 동작 | 지면 반응 |
|---|---|---|
| ~~초심자(미사용)~~ | 런타임 연결 제거 | 감시목 자산만 보관 |
| 온대 숲 | 뿌리를 밀어 올리며 기립 | 뿌리선, 낙엽 파편 |
| 맹그로브 | 낮은 자세로 물가에서 미끄러져 진입 | 청록 물기둥, 진흙 물결 |
| 마다가스카르 | 화면 위에서 낙하해 착지 | 붉은 흙, 씨앗·잎 파편 |
| 무인도 | 해안 방향에서 옆으로 출현 | 포말 호와 모래 물결 |

전용 FX는 `assets/fx/boss-entrance/boss-entrance-fx-atlas-pixel-v1.png`의 256px 셀, 6프레임×5행 아틀라스다. 이펙트는 보스 몸체와 같은 깊이 큐에서 지면 뒤/파편 앞 레이어로 나뉜다.

세계수 공성 보스는 이 공용 등장 FX를 사용하지 않는다. 사용자 줌을 유지한 채 SKYVIEW를 먼저 1.15초 보여 주고, 전용 `512×384` 6프레임 균열·흙판·수액광 아틀라스와 함께 4.8초 동안 상승한 뒤, 0.8초 기본 시점 복귀가 끝나야 전투가 열린다. 자세한 계약과 프레임 보드는 [`WORLDTREE_SIEGE_BOSS.md`](WORLDTREE_SIEGE_BOSS.md)에 있다.

## 검증

`scripts/verify_cinematic_camera_boss_intro.lua`가 다음을 검사한다.

- 롤·관성·줌 펀치의 상한과 감쇠
- 회전 카메라의 화면→월드 좌표 역변환
- 활성 4개 지역의 서로 다른 FX 행과 등장 동작
- 착지 임펄스 1회, 등장 종료 후 포즈 상태 정리
- 전투 정지 연결, 전경 평면 연결, 텍스트 등장 배너 부재
