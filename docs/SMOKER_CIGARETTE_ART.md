# 흡연자 담배 픽셀 재질

**투척 후 동작:** [바닥 잔류 꽁초와 확률적 착화](SMOKER_GROUND_EMBERS.md)를 따른다. 아래 내용은 입에 문 담배의 제작 규격이다.

사용자 요청: 큰 담배를 유지하면서 단순 저해상도 픽셀 확대가 아닌 고밀도 픽셀, 셰이더와 명암 그라데이션으로 표현한다.

- 최종 장비: `assets/characters/ingame/smoker-cigarette-pixel-v2.png`, 256×48 RGBA, 불투명 픽셀 70색, 이진 알파.
- 제작 원본: `assets/shaders/cigarette-material.glsl`. 필터 기공, 종이 결, 원통형 명암, 재와 불씨를 고정 그리드에 직접 계산한다. 재질별 16단계 색상 램프에 순서 디더링을 적용한다.
- 런타임: `src/cigarette_sprite.lua`. 몸체의 4×2 조각 확대를 제거하고 전용 장비 스프라이트를 등방 배율로 표시한다. 입부터 불씨까지 월드 길이는 24다. 기존 캐릭터 시트, 발선, 좌우 보정은 유지한다.
- 효과: `cigarette-ember.glsl`은 실제 붉은 재 균열에만 밝기 변화를 주고, `cigarette-smoke.glsl`은 192×384 고정 그리드에 휘어지는 연기 가닥을 계산한다. 연기 영역은 월드 60×120으로 이전 폭·높이의 3배이며 픽셀 밀도는 유지한다. 기존 큰 네모 불씨를 덧그리지 않는다.
- 제작/검증: `python scripts/build_cigarette_pixel_sprite.py --preview <출력 경로>`. Pillow와 moderngl 필요. 독립 오프스크린 GL 컨텍스트로 재질을 굽고 불씨·연기 셰이더를 컴파일·렌더한다. 게임 창을 실행하지 않는다.

## 생성 원화 기록

내장 ImageGen으로 `assets/characters/concepts/smoker-cigarette-reference-v1.png`를 생성했다. 이 이미지는 실사풍 원화에 가까워 최종 픽셀 스프라이트로 채택하지 않았으며 런타임에서 읽지 않는다. 최종 픽셀은 위 제작 셰이더가 직접 작성하며 원화를 샘플링하지 않는다. 원본은 보존한다.

생성 프롬프트: 단일 수평 담배, 왼쪽 필터와 오른쪽 불씨, 투명 배경, 글자·손·연기 제외. 황토색 코르크 필터의 미세 기공, 아이보리 종이의 섬유와 이음선, 원통형 명암 그라데이션, 불규칙한 회색 재와 주황색 균열을 고해상도 픽셀 일러스트로 표현. 낮은 해상도의 색 블록, 벡터 아이콘, 직사각형 불씨 금지. 전체 담배를 캔버스 안에 배치.
