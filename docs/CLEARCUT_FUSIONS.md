# 벌목 모드 융합스킬 — 조건, 획득, 검증

## 왜 인게임에 안 뜨는 것처럼 보였나

기존 `checkEvolutions`에 6종의 만렙 조합 판정과 일부 효과가 이미 있었다. 그러나 조건을 충족하면 `evolutions` 불리언을 바로 켜고 잠깐 알림을 표시했을 뿐, 융합 획득 카드가 없었다. 일반 업그레이드 선택지에도 융합은 들어 있지 않았다. 조합 진행도 안내도 없어서 무엇을 마스터해야 하는지 알기 어려웠다.

효과에도 누락이 있었다. 무한 야근은 설명과 달리 주변 나무를 때리는 충격파 없이 작은 적 피해만 줬고, 생태계 다이어트는 직접 살포에만 불모지 효과가 붙었다. 벌목 붕괴는 다음 나무의 벌목 연출이 방향을 다시 무작위로 정해 연쇄가 되돌아갈 수 있었다.

## 현재 획득 규칙

1. **아래 두 재료를 모두 만렙**으로 만든다. 현재 재료는 각각 Lv.6이며, 판정은 스킬 정의의 `max`를 읽는다. 로비 영구 특성 레벨이 아니라 이번 런의 스킬 레벨이다.
2. 마지막 재료를 고르는 즉시 게임이 멈추고 **확정 융합 획득 화면**이 열린다. 상자·추가 레벨업·확률 추첨은 필요 없다.
3. 버튼 클릭, `1`, `Enter`, 숫자패드 Enter 또는 Space로 획득한다. 원래 재료 스킬을 소비하지 않으며, 융합 자체도 남은 레벨업 횟수를 소모하지 않는다.
4. 동시에 완성된 융합은 순서대로 모두 받는다. 이후 남아 있던 레벨업 선택으로 돌아간다.
5. 획득한 융합은 같은 런의 다음 스테이지에도 유지된다. 새 런에서는 초기화된다.

직업 전용 조합은 해당 직업에게만 열린다. 죽은 땅은 공용이다. 재료를 배니시하면 미완성 조합은 완성할 수 없으며 진행표에 `재료 제외됨`이 표시된다. 융합 획득 화면에서는 배니시·리롤을 할 수 없다.

## 구현된 조합 8종

| 융합 | 직업 | 둘 다 MAX인 재료 | 실제 효과 |
|---|---|---|---|
| 산불 | 흡연자 | 꽁초 투척 + 건조주의보 무시 | 3초마다 추가 꽁초 투척. 붙은 불의 확산 반경 ×1.35, 초당 확산 확률 계수 ×1.5. 기름 빌드와 분리된 순수 산불 빌드 |
| 무한 야근 | 나무꾼 | 이번 달 목표 초과 + 산재 위험수당 | 10콤보부터 도끼 접촉 1회당 반경 145 충격파 1회. 나무 3 피해, 적 12 피해. 다중 타격 수만큼 중복 발동하지 않음 |
| 기름을 실수로 붓다 | 흡연자 | 라이터 기름 유출 + 마른 건초더미 생성 | 이동 경로에 이어진 기름 자국을 남기고 꽁초가 닿으면 연결된 화염대로 점화 |
| 무한 리필 | 비건 단체 회장 | 대왕 포크 + 접시 비우기 | 포크 피해와 동시 표적 수 증가. 섭취 후 가속 지속시간 증가 |
| 뉴타운 계획 | 개발업자 | 중장비 투입 + 부지 정지 작업 | 돌진 종료 지점 반경 160 안의 나무·그루터기를 불모지로 만듦. 범위 내 생존 나무를 즉사시키는 효과는 아님 |
| 비겁한 와다다다 | 코인 채굴꾼 | 손톱 강화 — 복리 발톱 + 지하 강제집행 | 잠복 중 이동 여부와 관계없이 실제 공격 지점을 빠르게 연속 할퀴며, 손톱자국 하나에 닿은 모든 나무·적에게 피해. 대상 수와 무관하게 타격당 FX 1개 |
| 영원회귀 | 차라투스트라 | 각주 남발 + 침샘 발달 | 최고 장광설을 끝낼 때 마지막 지점에 맑은 말의 잔향을 7초간 남김. 범위에 새로 들어온 대상도 반복 피해·중독 |
| 모두가 이해한 척했다 | 차라투스트라 | 끝없는 설교 + 부흥회 강화 | 부흥회 동안 신도들이 최대 3개 목표 지점에 음성 덩어리를 복창하고, 도착 프레임에 범위 피해 |

불모지는 해당 위치의 나무 재생을 막는다. 이전에 쓰러뜨린 나무를 죽은 땅 획득 시 소급 변환하지 않는다. 무한 야근은 기존 콤보가 끊기면 중단되고 다시 10콤보를 쌓으면 활성화된다. 산불의 강화는 이미 붙은 나무 화재에 적용하며, 투척 즉시 나무를 점화하는 효과로 되돌리지 않는다.

## 함께 수정한 선택 흐름

- 레벨업 화면 하단에 직업별 융합 조합, 재료별 현재 레벨/만렙, 획득 여부 표시.
- HUD의 `융합:` 목록은 같은 조합 정의에서 이름을 읽음.
- 상자는 대기 중인 XP 레벨업 횟수를 차감하지 않음. 상자 여러 개가 동시에 선택 화면을 덮어쓰지 않음.
- 모든 선택 가능한 스킬을 마스터하거나 배니시해 빈 풀이 되면 `현장 휴식`(체력 20 회복)으로 진행 가능.
- 960×540 최소 창에서는 선택 화면 전체를 축소하고 클릭 좌표도 같이 변환. 기본 1280×720에서 진행표가 화면 안에 들어감.
- 기존 아르카나와 희귀 스페셜 카드는 융합과 별개로 유지.

미리보기는 **실제 Lua UI 그리기 명령을 Pillow로 재생한 레이아웃 검수**다. 실행 중인 게임 캡처가 아니며 글꼴 래스터화는 LÖVE와 조금 다를 수 있다. 게임 창은 실행하지 않았다. 일반 카드의 기존 장식 셰이더를 새로 만든 작업도 아니다. 기존 전투 FX를 재사용했다.

```text
python scripts/headless_lua.py scripts/verify_clearcut_fusions.lua
python scripts/render_fusion_preview.py
```

첫 검사는 LÖVE Lua DLL, 두 번째는 추가로 Pillow가 필요하다. 융합 회귀 검사와 9개 UI 미리보기(7종·진행표·최소 창)를 생성할 수 있다. 두더지 융합은 별도 표시 크기·3배 픽셀 검수를 함께 사용한다.
