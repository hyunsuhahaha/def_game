# 숲 전멸 맵 4종 — 구현 기록

스타일은 [공통 그래픽 가이드](GRAPHICS_STYLE_GUIDE.md), 지역 생물의 근거와 구현/확장 후보 구분은 [생태 조사](BIOME_ECOLOGY.md), 나무별 식별점은 [혼합 식생](BIOME_VEGETATION.md)을 따른다.

## 플레이 연결

캐릭터 선택 → 맵 선택(숫자 1–4 또는 클릭) → 시작. ESC는 캐릭터 선택으로 돌아간다. 재시작과 다음 스테이지도 선택한 맵을 유지한다. 여섯 직업 전체에 연결했다.

| 맵 | 지형/나무 | 환경 생물/식물 | 첫 목표 |
|---|---|---|---|
| 온대 숲 | 기존 4종 나무와 능선·낙엽·바위 | 기존 숲 소품 유지 | 260 |
| 맹그로브 | 얕은 기수 물길, 진흙 둑, 지주뿌리 맹그로브·아비세니아·니파야자 | 물가의 농게형 게 | 230 |
| 마다가스카르 | 붉은 흙, 통형 바오밥 v2·타마린드·코미포라 | 환경용 여우원숭이, 부채잎 식물 | 220 |
| 무인도 | 불규칙한 해안, 백사장, 코코넛야자·바다아몬드·판다누스, 사방의 바다 | 비행하는 앵무새, 해변의 게 | 280 |

맹그로브 물길은 이동 가능한 얕은 물이고, 나무·바위는 물길에서 제외한다. 무인도는 해안 밖으로 걷거나 돌진할 수 없다. 적/보스도 육지에 생성되고 육지 안에 머문다. 기존 꽁초·불 전이·융합 효과를 재정의하지 않았다.

무인도 카메라는 섬 중앙에 고정하고 화면 크기에 따라 자동 맞춤한다. Ctrl+휠 확대는 무시해 해안이 잘리지 않게 한다. 사용자 피드백으로 육지 반경을 650×330에서 **1300×660으로 확대(실제 면적 4배)**했고 월드는 3400×2200이다. 첫 목표는 **280그루**, 다음 스테이지마다 60그루씩 늘어 최대 520그루다. 다른 맵은 매 스테이지 45그루씩 늘어난다. 이동 속도·발화 범위를 함께 키우지 않아 실제 횡단 거리와 태울 대상이 늘어난다. 중앙 시작 공간은 기존 월드 크기를 유지하므로 더 이상 섬 대부분을 비우지 않는다.

섬의 충돌·나무 배치·해변 게·앵무새·지형 셰이더는 `Maps.island`의 같은 반경을 사용한다. 해변 게는 28마리, 앵무새는 12마리로 늘렸다. 큰 섬의 후반 스테이지가 목표 수에 못 미치지 않도록 육지 후보 탐색 횟수를 목표 수에 비례해 늘린다. 난이도 체감과 클리어 시간은 라이브 플레이로 검증하지 않았으며, 여기서 확인한 것은 면적·목표·실배치·경계·화면이다.

## 지역 전투 적

일반 웨이브·시간 스폰·정예가 공통 `spawnEnemy`를 통과할 때 맵에 맞는 종으로 바뀐다. 온대 숲의 기존 적과 공통 보스/사신은 유지한다.

| 지역 | 전투 적 | 동작 |
|---|---|---|
| 맹그로브 | 늪지 게 / 바다악어 | 게는 근접 추격. 악어는 물길에서 등장, 0.65초 방향 예고 뒤 0.42초 돌진, 0.9초 회복 |
| 마다가스카르 | 화난 알락꼬리여우원숭이 | 0.32초 방향 예고 뒤 0.26초 도약, 0.45초 회복 |
| 무인도 | 해변 게 | 근접 추격·집게 접촉 공격 |

예고 화살표는 수관 위에 표시되고 공격 방향은 예고 시 고정되어 옆으로 피할 수 있다. 돌진은 이동 구간 전체로 충돌을 확인하되 한 공격에 한 번만 맞는다. 악어 생성 위치를 물길로 옮길 때 플레이어 바로 옆으로 이동하지 않도록 거리를 검사한다. 실제 종의 공격 행동을 재현했다는 의미는 아니다.

## 표현과 자산

- `clearcut-terrain.glsl`: 2텍셀/월드 단위 지형 그리드, 단계 명암, 제한 디더링, 이동하는 수면·해안선. 섬 바다는 월드 바깥까지 이어져 넓은 화면에 검은 사각 테두리가 생기지 않는다.
- 나무 9종: 맹그로브 232×244 / 바오밥 184×252 / 야자수 188×242 / 아비세니아 204×218 / 니파야자 208×188 / 타마린드 212×224 / 코미포라 188×216 / 판다누스 196×208 / 바다아몬드 218×230. 고정 발선 .91. 맹그로브·야자수·바오밥은 v2를 사용한다. 바오밥은 길고 가지 없는 통형 줄기와 꼭대기 수관이다.
- 크기나 색만 바꾼 동일 나무를 서로 다른 종으로 세지 않는다. 물길 거리·해안 거리·붉은 흙길에 따라 종별 군락을 달리한다. 제작 셰이더의 내부 외곽선은 2원생 픽셀, 재질 팔레트 안의 어두운 색으로 처리한다.
- 전투 적은 동일 고정 원화에서 6걷기/6공격 위상 아틀라스를 만든다. 악어 셀 224², 여우원숭이 192², 게 128². 현재 공통 변형 리그이며 개별 다리/턱의 분리 관절 리그는 아니다. 공격 행은 예고/돌진 상태에 연결한다.
- 환경: 앵무새 192×160 / 여우원숭이 192×192 / 게 128×112 / 부채잎 256×224. 원생 그리드, 재질 램프, 불투명/투명 알파, nearest 필터.
- 환경 생물은 독립적인 결정적 배치를 사용해 전투 난수를 소비하지 않는다. 앵무새는 수관 위 비행 궤적·방향 전환, 지상 생물은 작은 이동·방향 전환을 쓴다. **현재 단일 포즈 자산으로, 별도 날갯짓/다리 관절 애니메이션 시트는 없다.**
- 나무/지상 생물/플레이어는 동일한 깊이 정렬, 비행 새는 수관 위. 플레이어를 가리는 부채잎은 반투명 처리한다.

ImageGen 내장 도구를 자산별 별도 호출하여 원화를 만들고, 기존 승인 v3와 동일한 `forest-arcade-bake.glsl` GPU 제작 과정으로 최종 파일을 만들었다. 생성 원본과 초기 바오밥은 보존한다.

## 검증 및 재현

- `scripts/verify_clearcut_maps.lua`: 맵 4종, 스테이지 1–5 목표, 모든 직업의 선택, 키보드/클릭/취소, 재시작, 지역별 서로 다른 나무 3종, 나무·소품의 물 제외, 섬 걷기/돌진/적/보스 경계, 960×540~2560×1080 카메라. 지역 웨이브/시간/정예 스폰, 악어 수중 생성, 적 좌우 반전, 공격 예고/단일 충돌/회복/옆 회피도 검사한다.
- `scripts/render_clearcut_maps.py`: 실제 Lua World/Camera/Player와 전투 오버레이 경로를 기록하고 독립 GPU에서 재생. 4개 맵, 환경 이동 3종, 악어/여우원숭이 공격 2종, 960×540/1280×720 선택 UI를 검사한다. HUD·오디오·실시간 입력은 포함하지 않는다. 공격 검수는 시작 빈터에 적을 배치한 통제된 상황이며 실제 AI와 렌더 함수를 사용한다.
- `scripts/build_biome_trees.py`, `scripts/build_biome_life.py`, `scripts/build_biome_enemies.py`: 원생 크기·팔레트·알파·발선·애니메이션 위상을 검사하며 자산 재생성.

2026-08-26 검증: 새 맵/식생/전투 검사와 GPU 렌더 통과. 확대 후 고정 시드의 수종별 실제 배치는 맹그로브 108/95/27, 마다가스카르 44/71/105, 무인도 101/145/34이며 추가 시드 17/83/421에서도 세 종과 목표 수를 확인했다. 전체 Lua 검사 15개 중 14개 통과, `verify_clearcut_actions.lua` 1개 실패: 기존 도끼 타이밍 테스트가 현재 `updatePhysicalAttack`의 `playAutoAxeSwing` 호출/공격 방식과 맞지 않는다. 맵 변경으로 해결한 것으로 표시하지 않는다.

게임 창은 실행하지 않았다. 미리보기는 실제 Lua 명령의 오프스크린 GPU 재생이며 라이브 LÖVE 캡처가 아니다. GPU는 AMD Radeon(TM) Graphics, 맵 렌더에 사용한 셰이더 4개를 컴파일했다.
