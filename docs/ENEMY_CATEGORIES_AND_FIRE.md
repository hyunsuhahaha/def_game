# 몬스터 생태 카테고리와 식물형 화상 규격

## 필수 카테고리

모든 몬스터 정의는 `category="plant"` 또는 `category="animal"`을 반드시 가진다. `src/clearcut_mode.lua`가 전체 정의를 합친 직후 이 값을 검사하므로 새 몬스터가 분류 없이 추가되면 로딩 단계에서 실패한다. 이후 스킬의 우선 대상, 추가 피해, 상태이상 면역은 이름 목록을 따로 만들지 않고 이 필드를 사용한다.

스킬 로직에서는 `mode:enemyHasCategory(enemy,"plant")` 또는 `mode:enemyHasCategory(enemy,"animal")` 공용 질의를 사용한다.

- `plant`: 나무·덩굴·버섯·공격 식물·재생 성소와 식물형 보스. 게임플레이상 불이 붙는 생태군이다.
- `animal`: 다람쥐·멧돼지·악어·원숭이·게·소라게 등 비식물형 적. 숲의 사신도 현재 이진 전투 분류에서는 비식물형인 `animal`로 취급한다.

버섯을 `plant`에 포함하는 것은 생물학 분류가 아니라 화염 및 식물 대상 스킬을 위한 게임플레이 분류다.

## 식물형 화상

- 식물형 적만 꽁초 불씨, 날아가는 꽁초 직격, 타는 나무, 건초 화염 지대와 불붙은 기름길에 점화된다.
- 화상은 하나의 boolean 상태이며 중첩 횟수나 중첩 피해가 없다. 타는 동안 다시 점화해도 지속시간과 틱 타이머를 갱신하지 않는다.
- 점화 후 4초 동안 0.5초 간격으로 8회 피해를 받고 자동으로 꺼진다.
- 화상 피해는 불이 옮겨온 깊이에 따라 줄어들지 않는다. 스킬 레벨에 따른 단일 틱 피해만 사용한다.
- 비가 오면 기존 식물형 화상도 즉시 꺼지고 새로운 점화가 막힌다.
- 불꽃과 연기는 나무에 쓰는 고밀도 담배 불 FX 셰이더를 재사용하며, 적의 반경에 맞춰 작은 식물 2개 불꽃, 중형 3개, 초대형 7개 불꽃층으로 표시한다.
- 동물형은 화염 지대의 직접 피해를 받을 수 있지만 `burning` 상태가 되거나 몸에 지속 불꽃이 붙지는 않는다.

실제 런타임 몸체와 셰이더를 오프스크린에서 합성한 표시 크기 검수본은 [`previews/enemy-plant-fire-v1.png`](previews/enemy-plant-fire-v1.png)이다.

## 검증

`scripts/verify_enemy_categories_and_fire.lua`가 전체 정의의 카테고리, 식물/동물 점화 분리, 비중첩, 4초 자동 소화, 8틱 피해, 꽁초 불씨 대상 선택과 실제 불 FX 셰이더 연결을 검사한다.
