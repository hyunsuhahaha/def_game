# 월드 덩굴 식생

화면에 고정된 전경 넝쿨은 사용하지 않는다. 우거진 숲은 실제 월드 좌표와 깊이 정렬을 가진 식생으로 표현한다.

## 구성

- 나무 부착형 2종: 살아 있는 목표 나무의 줄기와 수관 아래를 타고 올라간다. 나무가 쓰러지기 시작하거나 사라지면 함께 사라진다.
- 바닥 군락 4상태: 평상, 왼쪽으로 눕기, 오른쪽으로 눕기, 절단 상태를 같은 뿌리 좌표에서 사용한다.
- 지역 밀도: 맹그로브가 가장 풍부하고 온대 숲·무인도는 중간, 마다가스카르는 성기게 배치한다. 초심자 프로필은 미사용 자산으로 보관한다.
- 상호작용: 플레이어가 지나가면 이동 방향으로 바스락거리며 눕고, 공격 범위에 닿으면 잘린 뒤 해당 스테이지에서 다시 자라지 않는다.

## 렌더 계약

`assets/scenery/biomes/world-vines-atlas-pixel-v1.png`은 160×224 셀 6개로 구성된 960×224 RGBA 아틀라스다. 고정 원생 픽셀, 불투명 알파 경계, 짙은 유색 외곽선, 줄기·잎의 단계 명암을 사용한다. 런타임은 `nearest` 필터를 사용한다.

`src/biome_vines.lua`가 독립 난수로 배치해 전투 난수에 영향을 주지 않는다. 나무 부착형은 숙주 나무의 발 좌표 바로 뒤 순서로, 바닥 군락은 자신의 뿌리 좌표로 월드 빌보드 큐에 들어간다. 따라서 2.5D 카메라 이동·줌·원근·공통 흔들림을 다른 인게임 오브젝트와 동일하게 받는다.
