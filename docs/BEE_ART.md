# 벌 픽셀 아트

벌은 일반 몬스터가 아니라 벌집과 함께 나타나는 작은 환경 위험물이다. 따라서 다람쥐만큼 크게 만들지 않고, 실제 표시 크기에서 노란 배·짙은 줄무늬·밝은 날개·침만 즉시 읽히게 한다.

- 런타임 자산: `assets/fx/bees/bee-flight-simple-pixel-v2.png`
- 규격: 6열×1행, 셀 32×24px, 전체 192×24px
- 팔레트: 11색, 투명 RGBA, nearest 필터
- 표시 배율: 벌집 주변 1.02, 추적 벌떼 1.30. 기본 카메라 줌 0.72에서 각각 약 18px·23px 폭의 핵심 실루엣이 남는다.
- 애니메이션: 몸의 크기와 중심은 고정하고 날개만 위·중간·아래로 움직인다.
- 금지: 큰 몬스터 체급, 사실적인 털, 거대한 눈, 복잡한 반투명 날개, 런타임 타원 조립식 몸체

고밀도 생성 원화를 그대로 축소한 v1은 사용자가 벌치고 너무 크고 복잡하다고 판단했으므로 런타임에 연결하지 않는다. 최종 v2는 작은 화면 가독성을 위해 형태와 색을 의도적으로 간소화했다.
