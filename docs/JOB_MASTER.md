# 잡 마스터와 건설업자

현재 기록전 연구망의 `fire`와 `universal`에 속한 **활성 노드 전부**가 만렙이면 흡연자가 **잡 마스터**가 된다. 보존된 캠페인 노드는 조건에 포함하지 않는다. 마지막 연구 구매 시 바로 저장되며, 기존 만렙 저장도 다음 기록전 시작 시 전환한다.

코인, 재생 단계, 연구 레벨을 초기화하지 않는다. `character_traits.sav` 버전 8의 `job_master_fire`로 전환을 저장하고, 기존 버전 7 저장은 구매 내역을 유지한 채 읽는다. 건설업자는 별도의 `builder_*` 연구 10개(37랭크)를 0부터 육성한다. 연구 보드는 전환 직후 건설업자 연구망을 표시한다. 다음 기록전과 재도전부터 건설업자를 직접 조작한다.

## 완성된 흡연자의 자동 전투

로비의 **캐릭터 선택(C)** 창은 기존 디펜스 버튼을 대체한다. 흡연자와 건설업자 크레인을 고른 뒤 선택 완료로 로비에 돌아와 게임 시작을 누른다. 좌우/1·2/Tab으로 탐색하고 Enter로 확정하며 Esc는 변경 없이 취소한다. 크레인은 잡 마스터 전에는 잠겨 있다. 해금 후 흡연자를 고르면 기존 흡연자를 직접 조종하고 별도 자동 흡연자를 중복 생성하지 않는다. 크레인을 고르면 아래의 자동 전투를 사용한다. 선택은 현재 실행 세션과 재도전에서 유지하며, 앱을 다시 켜면 진행도에 따른 기본 직업을 사용한다. 디펜스 구현은 보존하되 로비 버튼·D 단축키는 제거했다.

잡 마스터의 플레이어 객체, 영구 수치, 담배 재장전, 도끼·화염방사기·폭죽 공격과 기존 동료·설비 런타임을 그대로 사용한다. 피해 배율이나 공격속도를 낮추지 않는다. 기존 무기 전수 원숭이는 원래 성능으로 그대로 동행하며, 잡 마스터 자체에는 원숭이의 절반 성능 규칙을 적용하지 않는다.

흡연자는 살아 있는 가까운 나무를 조준하고 사거리까지 이동한다. 나무가 없으면 세계수를 겨냥한다. 먼 목표에는 해금된 대시를 자동 사용한다. 비로 불이 꺼질 때는 가까이 접근해 기존 도끼 문맥 공격을 사용한다. 자동 공격은 플레이어의 클릭·마우스 위치와 독립적이다. 숲 공급·세계수·정산은 한 번만 갱신하고 양쪽의 벌목 성과를 같은 런에 합산한다.

## 건설업자

건설업자는 별도로 걸어 다니는 사람이 아니라 **플레이어가 직접 조종하는 대형 크레인**이다. WASD로 궤도식 크레인 본체를 이동하고, 마우스로 붐 방향을 조준하며 좌클릭으로 자재를 투하한다. 기존 개발업자 사람 스프라이트는 보존하지만 이 직업에는 연결하지 않는다. 카메라는 본체 기준 위쪽 250을 추적하고 본체의 맵 경계 여유는 160이다.

철탑은 약 630 월드 단위 높이이며, 864 폭의 긴 붐과 넓은 주행 하부를 사용한다. 이동 시 궤도 6프레임을 재생한다. 본체 앞 280 거리에서 높이 320의 자재가 떨어지며, 0.4초 뒤 지면에 닿아 조준 방향으로 굴러간다. 투하 뒤 본체가 이동해도 자재는 독립적으로 진행한다. 같은 자재는 경로의 각 나무와 적을 한 번씩 연속 타격한다. 긴 프레임에도 선분 전체를 검사하여 빠른 자재가 나무를 통과하지 않는다. 지면 경계 또는 최대 거리에서 정리한다.

| 수치 | 기본 | 전용 연구 만렙 |
|---|---:|---:|
| 자재 피해 | 900 | 4,800 |
| 투하 주기 | 1.35초 | 0.75초 |
| 동시 자재 | 1 | 3 |
| 충돌 반경 | 42 | 82 |
| 굴림 속도 | 680 | 1,160 |
| 굴림 거리 | 1,100 | 1,900 |
| 세계수 피해 배율 | ×1 | ×3 |
| 추가 나무 허용량 | 0 | +60 |
| 크레인 본체 이동속도 | 320 | 422.4 |

비는 콘크리트 충돌 피해를 막지 않는다. 크기가 커지면 표시 크기와 충돌 반경을 함께 키운다. 연구 코인·재생 단계·맵 크기는 기존 진행을 공유한다. 이번 구현의 전직 경로는 흡연자 → 건설업자이며, 이후 직업은 아직 정의하지 않았다. 보존된 캠페인과 디펜스·기존 흡연자 연습장에는 전직을 강제하지 않는다.

## 아트와 검증

- `assets/construction/tower-crane-pixel-v2.png`: 448×896 원생 철골·운전실·사다리·작업 발판. 별도 `tower-jib-pixel-v2.png`는 1152×144, `crane-tracks-atlas-v1.png`는 448×128 셀 6프레임. 런타임 배율 .75. 구형 v1 고정 타워는 미연결 보존한다.
- `assets/construction/concrete-pipe-roll-atlas-v1.png`: 192×192 셀, 12프레임. 콘크리트 단면의 명암·철심이 회전한다. 모든 고체 알파는 0/255이고 필터는 nearest다.
- 제작: `python scripts/build_construction_assets.py`.
- 게임플레이: `python scripts/headless_lua.py scripts/verify_job_master.lua`.
- 실제 World 정렬 큐와 연구 보드 오프스크린 검수: `python scripts/render_job_master.py`. `.84` 표시 크기·2배 픽셀 뷰·8프레임 동작을 `docs/previews/job-master-*`에 만든다. 게임 창은 실행하지 않는다.
- 전체 회귀: `python scripts/headless_lua.py`, 자산 경로: `python scripts/verify_asset_versions.py`.
