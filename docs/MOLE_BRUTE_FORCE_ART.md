# 천재 두더지 — 브루트포스 어택

코인 채굴꾼의 해커 계열은 브루트포스 어택만 남긴다. 지상에서 발동하면 두더지 전방 205px에 잠긴 금색 비트코인 하드월렛이 나타난다. 두더지 손앞에서 0–9 숫자 패킷이 0.008초 간격으로 생성되어 0.30초 동안 길고 굵은 녹색 디지털 레이저를 타고 지갑에 두두둑 입력된다. 0.67초부터 지갑이 해독된 열림 프레임으로 바뀌고, 입력된 숫자가 지갑 위치에서 사방으로 발사되어 실제 투사체가 된다.
