# 무한 디펜스

## 플레이 규칙

- 원형 나무 띠 하나가 한 단계다.
- 시작 시 1~4단계가 동시에 존재하며 각 단계는 96그루다.
- 앞 단계의 제거 여부와 관계없이 2.5초마다 다음 단계가 바깥 유입선에서 생성된다.
- 모든 나무는 중앙을 향해 계속 이동한다.
- 이동 중 나무는 중앙 방향으로 기울어 흔들리고, 바깥쪽 뒤에는 흐르는 흙 끌림 자국이 남아 이동 방향이 보인다.
- 나무 한 그루라도 중앙 방어선에 닿으면 즉시 패배한다.
- 승리와 제한 시간은 없다.

## 현재 조정값

| 값 | 수치 |
|---|---:|
| 월드 / 플레이 영역 | 5120×3200 / 3840×2240 |
| 중앙 방어선 반경 | 110 |
| 시작 단계 반경 | 840 / 900 / 960 / 1020 |
| 이후 단계 유입 반경 | 1080 (시작 화면 밖) |
| 단계당 나무 | 96 |
| 새 단계 간격 | 2.5초 |
| 중앙 접근 속도 | 초당 20 월드 단위 |
| 단계 체력 증가 | `기본 체력 × (1 + (단계-1) × 0.12)` |

초기 4개 띠 사이 간격은 60이다. 5단계부터는 같은 외곽 유입선에서 2.5초 간격으로 생성되므로 이동 속도 기준 실제 띠 간격은 약 50이다. 한 띠에 96그루라 외곽에서도 수관이 맞물리고 중앙에 가까워질수록 완전히 겹친다. 화면 안에서 갑자기 생기지 않고 먼 맵 끝에서 여러 단계가 두꺼운 숲벽처럼 계속 다가오는 것이 주 압박이다.

## 코드 경계

- `src/defense_mode.lua`: 배치, 시간 기반 단계 생성, 체력 배율, 중앙 이동, 침범 패배
- `src/clearcut_mode.lua`: 기존 무기·불·동료 시뮬레이션과 HUD·결과 연결
- `src/game.lua`: 시작·재도전 상태 전환
- `src/lobby.lua`: `D` 진입점
- `scripts/verify_defense_mode.lua`: 단계 독립 생성, 체력 상승, 이동, 패배 회귀 검사
