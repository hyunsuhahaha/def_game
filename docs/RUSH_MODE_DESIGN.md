# 채집 러시 실험실 — 3분 수직 프로토타입

## 목적

기존 15분 작전 모드는 보존한다. 로비에서 별도로 진입하는 **채집 러시 실험실**은 최초 기획의 핵심 재미만 3분 안에 검증한다.

> Timber Rush식 폭발적인 채집 성장과 뱀서류의 자동 전투·3택 빌드 성장을 하나의 즉각적인 피드백 고리로 연결한다.

검증 질문은 하나다.

> 나무를 더 빠르고 넓게 쓸어버릴수록 전선의 자동 화력도 즉시 폭주하는가?

## 모드 분리 원칙

- 기존 `작전 시작`은 현재 15분 농사·채광·벌목·건설·방벽 시스템을 그대로 사용한다.
- 신규 `채집 러시 실험실`만 3분 규칙과 전용 강화 풀을 사용한다.
- 영구 재화와 기존 특성은 러시 밸런스 검증을 흐리지 않도록 적용하지 않는다.
- 신규 코드는 `RushMode` 상태 객체에 모아 실험 실패 시 쉽게 제거하거나 교체할 수 있게 한다.

## 3분 플레이 루프

```text
밀집된 숲으로 이동
→ 나무를 직접 클릭해 벌목
→ 목재 다발이 화면에 폭발
→ 넓은 범위에서 자동으로 흡수
→ 생산 경험치 충전
→ 3개 강화 중 하나 선택
→ 다수 타격·광역 범위·연쇄 벌목·자석 흡수 성장
→ 누적 목재가 자동 포탑 수와 전선 화력을 강화
→ 더 많은 나무와 적을 동시에 쓸어버림
```

## 시간별 목표 감각

| 시간 | 목표 경험 |
|---|---|
| 0:00–0:30 | 한 그루씩 베고 첫 3택을 빠르게 획득 |
| 0:30–1:00 | 한 번의 도끼질이 주변 2–3그루에 전달 |
| 1:00–2:00 | 연쇄 벌목과 자동 흡수로 숲의 덩어리가 무너짐 |
| 2:00–3:00 | 목재가 폭발적으로 쌓이고 자동 전선이 다수 포탑으로 폭주 |

## 전용 강화

- **쌍날 도끼**: 한 번에 타격하는 나무 수 증가
- **넓은 휘두르기**: 광역 벌목 반경 증가
- **연쇄 벌목**: 나무 파괴 시 주변 나무로 파괴 충격 전달
- **강력 자석**: 목재 자동 흡수 반경과 속도 증가
- **과충전 도끼**: 벌목 타격 속도 증가
- **풍성한 수확**: 나무 한 그루의 목재 드롭 증가

고정 클래스나 테크 선택은 없다. 매 레벨 3택에서 자유롭게 섞는다.

## 채집과 전투의 연결

누적 획득 목재는 별도의 건설 메뉴 없이 즉시 자동 전선으로 변환된다.

- 목재 0: 기본 자동 화력
- 목재 35: 첫 보조 포탑
- 이후 목재 55개마다 보조 포탑 추가, 최대 4기
- 누적 목재에 비례해 코어 공격력과 공격 속도 증가
- 화력 단계 상승 시 화면 중앙에 즉시 알림과 강화 파동 표시

플레이어는 포탑에 접근하거나 건설 위치를 선택하지 않는다. 계속 채집하는 것이 곧 전투 조작이다.

벌목은 나무를 하나씩 정확히 클릭하지 않는다. 마우스 왼쪽 버튼을 누른 채 이동하면 플레이어의 도끼 범위 안에 들어온 가장 가까운 나무를 자동 포착하고, 도끼 속도에 맞춰 광역 타격한다. 따라서 조작의 중심은 클릭 정확도가 아니라 이동 경로와 숲 밀집도를 읽는 판단이다.

맵은 금속 생산시설 바닥을 재사용하지 않는다. 러시 모드 전용 모듈형 숲 바닥 위에 자연형 나무 군락, 중앙 작업 공터, 방벽까지 이어지는 흙길을 독립적으로 배치한다. 베어진 나무는 즉시 사라지는 대신 그루터기로 남고, 새싹 단계를 거쳐 같은 자리에서 다시 자라 자원 순환을 눈으로 확인할 수 있다.

메인 카메라는 플레이어와 채집 쾌감을 크게 보여준다. 동시에 우측 상단의 **실시간 전선 중계창**은 같은 연결 월드의 북쪽 전투 구역 전체를 축소해서 보여준다. 따라서 숲을 벨 때도 적 밀집도, 포탑 일제사격, 방벽 체력을 한눈에 확인할 수 있다.

## 의도적으로 제외하는 기능

- 씨앗 심기와 물주기
- 채광과 도구 구매
- 수동 포탑 건설 및 `F` 강화
- 수동 납품과 작은 가방 제한
- 방벽 강화 메뉴
- 영구 특성 보정

기능 삭제가 아니라 러시 모드에서만 비활성화한다.

## 성공 지표

- 25초 안에 첫 3택이 등장한다.
- 60초 안에 한 번의 행동으로 2그루 이상을 타격한다.
- 120초 안에 연쇄 파괴 또는 넓은 자동 흡수가 작동한다.
- 마지막 30초의 분당 채집량이 첫 30초의 5배 이상이다.
- 목재 획득 후 1초 안에 전선 화력 변화가 보인다.
- 3분 종료 후 결과 화면에서 초반/후반 채집 속도를 비교할 수 있다.

## 피드백 루프

런 결과에 다음 값을 기록한다.

- 총 목재
- 파괴한 나무 수
- 최대 동시 타격 수
- 최대 연쇄 파괴 수
- 최종 자동 화력 단계
- 첫 30초와 마지막 30초의 채집량
- 성장 배율 `마지막 30초 ÷ 첫 30초`

성장 배율이 낮으면 그래픽을 추가하지 않고 레벨업 간격, 광역 반경, 연쇄 계수를 먼저 조정한다.
