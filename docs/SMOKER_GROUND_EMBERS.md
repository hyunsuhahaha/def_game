# 흡연자: 바닥에 남는 꽁초와 확률적 착화

그래픽 작업은 [공통 스타일 가이드](GRAPHICS_STYLE_GUIDE.md)를 따른다. 이 변경은 사용자가 요청한 **투척 → 잔류 꽁초 → 확률적 불씨 전이 → 나무 착화**를 실제 게임 상태와 시각 표현 양쪽에 적용한 것이다.

## 게임 규칙

| 단계 | 동작 | 플레이어에게 보이는 것 |
|---|---|---|
| 투척 | 기존 손가락 방출 프레임에서 최소 0.22초·초당 1200 월드 단위로 빠르게 비행 | 회전하는 고밀도 꽁초, 끝의 밝은 불씨 |
| 착지 | 조준한 바닥 위치에 꽁초를 생성하고 반경 안의 최근접 유효 대상 하나를 즉시 점화. 광역 피해는 없음 | 착지 파편과 착화 버스트, 대상의 짧은 반동·플래시, 남아 있는 꽁초 |
| 접촉 박자 | 첫 점화 또는 비행 중 적 직격에 0.025~0.03초의 짧은 정지와 전용 접촉음을 적용 | 고음의 탁 소리와 낮은 툭 소리, 공격 결과가 보이는 짧은 정지 |
| 잔류 | 최초 대상 점화 뒤에도 착지부터 7초간 연소. 0.15초 대기 후 0.55초마다 추가 대상 하나에 시도 | 줄어드는 종이, 잿빛 탄 부분, 잔불, 연기, 7칸의 남은 시간 표시 |
| 시도 실패 | 나무에 불을 붙이지 않고 다음 시도까지 대기 | 꽁초 끝의 짧은 불씨 튐. 나무로 가는 가짜 연결선은 없음 |
| 시도 성공 | 성공한 대상에 이동 중 불씨를 생성. 이때도 나무는 아직 불타지 않음 | 꽁초 끝에서 나무 밑동으로 날아가는 밝은 불씨와 짧은 꼬리 |
| 불씨 도착 | 도착 순간 대상의 유효성을 다시 검사하고 실제 `burning` 설정 | 밑동의 불꽃 파편과 약 .45초간 커지는 픽셀 불꽃 |
| 수명 만료 | 새로운 착화 시도 중단. 1.5초간 차가운 꽁초를 남긴 뒤 제거 | 잔불·연기 소멸, 회색 꽁초와 꺼진 눈금이 서서히 사라짐 |
| 비 | 바닥 꽁초를 즉시 젖은 상태로 전환하고 이동 중 불씨를 취소 | 불씨·연기가 사라지고 회색 꽁초만 잠시 남음. 비가 그쳐도 재점화하지 않음 |

수치는 게임용 조정값이며 현실의 흡연·화재 물리를 설명하는 값이 아니다.

## 확률과 대상

- 전이 반경은 기존 조준 범위와 같은 `90 + 꽁초 투척 레벨 × 20` 월드 단위다. 착지 시 첫 대상 하나를 찾는 범위이자 이후 불씨 전이 범위이며 광역 피해 반경은 아니다.
- 착지 순간 활성·미연소 상태인 최근접 나무 또는 식물형 적 하나를 확정 점화한다. 비가 오거나 유효 대상이 없으면 즉시 점화하지 않는다.
- 매 시도마다 범위 안에서 **활성·미연소·다른 불씨가 향하지 않는 가장 가까운 나무 하나**를 고른다. 나무가 없으면 난수를 소비하지 않는다.
- 성공 확률: `min(.96, .90 + 건조주의보 레벨 × .02) × (1 − .15 × 경과시간/7) × (1 − .12 × 거리/반경)`.
- 기본 계수는 90%, 강화 상한은 96%다. 이 확률은 최초 접촉 뒤의 추가 확산에 적용되며, 만료 전까지 추가 전이가 모두 실패할 가능성과 실패 후 재시도는 남아 있다.
- 기본 7초 동안 최대 13회 시도한다: 착지 0.15초 뒤 첫 시도, 이후 0.55초 간격이다.
- 불씨 이동 시간은 `.12 + .10 × 거리/반경`초. 같은 나무로 동시에 불씨를 중복 예약하지 않는다.
- 도착 전에 베어진 나무, 이미 다른 불로 타는 나무, 범위를 벗어난 나무는 새로 점화하지 않는다. 기존 화재의 연소 시간을 초기화하지 않는다.
- 자동 투척과 만렙 추가 투척도 같은 최초 접촉·잔류 과정을 거친다. 자동 투척의 착지점은 선택한 나무 밑동 옆으로 약간 옮겨 꽁초가 줄기에 묻히지 않게 한다. 수동 조준점은 유지한다.
- 이미 붙은 불의 연소·적 피해·주변 확산과 기름/불씨 업그레이드의 후속 효과는 기존 규칙을 유지한다. 바닥 꽁초 자체는 접촉 피해를 주지 않는다.

시도·만료·불씨 도착은 절대 이벤트 시각으로 처리한다. 같은 난수 입력과 대상 상태에서 프레임을 잘게 나누거나 큰 `dt`를 주어도 착화 시도 수와 도착 시각이 같도록 검사했다. 게임 전체의 공유 난수 소비까지 모든 실행에서 동일하다는 뜻은 아니다. 렌더링은 이 상태를 읽기만 하고 확률을 굴리거나 착화하지 않는다.

## 그래픽과 연결

- [꽁초 원생 픽셀](../assets/characters/ingame/smoker-cigarette-butt-pixel-v1.png): 256×64, 69색, 이진 알파. 필터 기공·짧은 종이·그을림·부서진 재를 새 제작용 GLSL에서 굽는다. 기존 담배와 같은 재질 표현을 사용하며 작은 문자 그리드 확대 모델은 더 이상 투사체에 사용하지 않는다.
- 게임 표시 길이 32 월드 단위. `nearest` 필터, 실제 사용 그리드에서 재질별 16단계 명암. 기존 입에 문 담배 자산과 입 앵커는 바꾸지 않았다.
- 런타임 연소 셰이더는 종이 끝을 줄이고 탄 부분을 남긴다. 연기·불씨·불꽃은 별도 고정 그리드 FX이며 축당 최소 3.2 텍셀/월드 단위로 그린다.
- 꽁초 몸체와 그림자는 월드 지면 정렬 큐에 들어간다. 잔불·연기·불씨 전이·도착 파편은 별도 FX 레이어로 보이게 한다. 연료 눈금은 기능 표시이며 거대한 지속 범위 원으로 덮지 않는다.
- clearcut의 나무 연소 그림은 새 픽셀 불꽃·연기 렌더를 사용한다. 다른 모드의 기존 불꽃 경로는 유지한다.
- 시뮬레이션 시계로 잔류·전이 FX를 그려 일시정지 때도 불씨가 혼자 도착하는 모습을 만들지 않는다.
- 스테이지 전환 시 꽁초·전이·도착 FX와 대상 예약을 정리한다. 직업/업그레이드 설명도 폭발 대신 잔류·확률 전이로 수정했다.

핵심 코드: [상태와 확률](../src/cigarette_butts.lua), [시각 표현](../src/cigarette_butt_art.lua), [제작 스크립트](../scripts/build_cigarette_butt_sprite.py). 연결은 `ClearcutMode:updateMolotovs`, `queueWorldActors`, `drawCigaretteGroundEffects`, `World:draw`에 있다. `molotov` 식별자는 기존 업그레이드·진화와의 호환을 위해 유지한다.

## 검증과 미리보기

**게임 창은 실행하지 않았다.** 실제 상태 갱신과 World/Player/꽁초 렌더를 기록해 오프스크린 GPU에서 재생했다. HUD·실시간 입력·전체 재난/연소/벌목 시뮬레이션을 포함한 엔진 캡처는 아니다. 성공 과정은 첫 시도 실패/두 번째 성공의 고정 난수를 넣은 검증 사례다. 마지막 꺼진 꽁초 컷은 모든 시도가 실패한 별도 사례다.

- [동작 GIF](previews/smoker-ground-lifecycle.gif)
- [첫 접촉 확대](previews/smoker-ground-transfer-zoom.png)
- [꽁초 픽셀 확대](previews/smoker-ground-butt-pixels.png)

`verify_smoker_objects_and_developer_range.lua`는 빠른 비행, 착지 최초 대상 즉시 점화·접촉 박자, 0.15초 뒤 추가 확산, 성공 후 도착 전 무착화, 도착 시 점화, 확률 실패, 7초 만료/정리, 거리와 건조 보정, 대상 적합성/중복 방지, 비와 재점화 방지, 자동/추가 투척, 프레임 분할, 스테이지 정리, 실제 자산/FX/셰이더 복구를 검사한다. 기존 개발자 범위 검사도 유지한다.

새 제작·연소·FX 셰이더는 오프스크린 GPU에서 컴파일·렌더하고 실제 표시 크기와 확대를 검수했다. 빠른 투척·착화 변경 후 흡연자 꽁초 상태, 2.5D 비행 판정, 북쪽 경계 낙하, 문서 동기화 집중 검사 4종이 통과했다.

```text

python scripts/build_cigarette_butt_sprite.py --preview
python scripts/verify_forest_arcade_assets.py
```
