# 단일 수종 반복 금지 — 지역별 혼합 식생

**사용자 교정: 대표 나무 한 종을 크기만 바꿔 채우는 것은 숲 생태계가 아니다. 모든 지역은 여러 수종과 하층 식물의 군락으로 구성한다. 그래픽은 계속 카툰 2D 픽셀이며 식물학적 디테일을 핑계로 실사화하지 않는다.**

## 실제 생태를 바탕으로 한 제작 목록

### 맹그로브 — 뿌리 형태와 물길의 차이

| 식물 | 화면에서 구별할 형태 | 배치 |
|---|---|---|
| Rhizophora형 | 굵은 아치형 지주뿌리, 짙고 둥근 잎 덩어리 | 물길 양쪽과 안쪽 숲 |
| Avicennia형 | 밝은 회색 줄기, 낮은 수관, 지면에서 솟은 연필형 호흡근 | 개방된 진흙 물가에 가중치 |
| 니파야자 Nypa fruticans | 지상에 높은 줄기 없이 땅에서 솟는 깃 모양 잎 군락 | 상대적으로 잔잔한 위쪽 수로 주변 |
| 맹그로브 고사리 Acrostichum aureum | 길고 선 잎, 낮은 층의 잎 군락 | 육지 쪽 습한 가장자리. **전용 모델은 후속 제작 후보** |
| Acanthus류·황근 | 낮은 관목층/꽃 포인트 | 후방 맹그로브. **후속 제작 후보** |

NParks의 식생 자료는 여러 맹그로브 속, 바다 쪽 Avicennia/Sonneratia와 뒤쪽의 고사리·Acanthus·황근을 구분한다. 또한 교란 때문에 구역 경계가 항상 선명한 것은 아니라고 설명한다. 따라서 게임에서도 딱 잘린 3색 구획 대신 확률적으로 섞이는 군락을 만든다. [Flora of Singapore 식생 장](https://www.nparks.gov.sg/-/media/sbg/flora-of-singapore/volume-1-introduction/1%2C-d-%2C5_vegetation_lr.pdf)

니파는 지상 줄기가 드러나지 않는 군생 야자이며 조수가 드나드는 수로의 위쪽과 잔잔하고 진흙이 많은 환경에 어울린다. [NParks 니파야자](https://www.nparks.gov.sg/florafaunaweb/flora/2/6/2658). 호흡근의 형태는 [NUS Avicennia 자료](https://m.singapore.biodiversity.online/taxo4254/mainSpace/Avicennia%20alba.html), 고사리는 [NParks Acrostichum](https://www.nparks.gov.sg/florafaunaweb/flora/1/5/1535)를 참고했다.

### 마다가스카르 — 바오밥은 표지목, 나머지는 혼합 건조림

| 식물 | 화면에서 구별할 형태 | 배치 |
|---|---|---|
| Grandidier형 바오밥 | 길고 굵은 가지 없는 통형 줄기, 꼭대기의 작은 수관 | 약 20%의 표지목. 전체를 바오밥으로 덮지 않음 |
| 타마린드 Tamarindus indica | 넓고 낮은 둥근 수관, 아래서 갈라지는 갈색 줄기 | 중앙 통로/상대적으로 수분이 있는 구역에 가중치 |
| Commiphora형 건조림 나무 | 연한 껍질, 비틀린 드러난 가지, 작은 성긴 잎 덩어리 | 마른 바깥 구역에 가중치 |
| 여행자나무 Ravenala형 | 짧은 줄기와 평면 부채형 잎 | 소수의 식생 포인트. 숲 전체의 주 수종으로 쓰지 않음 |
| 건조 관목·풀·낙엽 | 낮은 층의 거친 덩어리 | 빈 공간 모두를 덮지 않도록 군락화. 전용 건조 관목 모델은 후속 후보 |

Kew는 바오밥을 낮은 고도의 건조림, 흔히 물웅덩이·강 주변과 연결하며 타마린드도 계절성 건조림·소림·강변과 연결한다. [Kew 바오밥](https://www.kew.org/plants/giant-baobab), [Kew 타마린드](https://powo.science.kew.org/taxon/urn%3Alsid%3Aipni.org%3Anames%3A520167-1/general-information)

Commiphora에는 마다가스카르의 계절성 건조 열대 환경에 사는 종이 있으며, 건조림 종의 뒤틀린 가지·성긴 수관을 확인할 수 있다. 게임 모델은 속 수준의 형태 참고이며 특정 종을 완전히 재현했다고 주장하지 않는다. [Kew 분포](https://powo.science.kew.org/taxon/urn%3Alsid%3Aipni.org%3Anames%3A77160106-1/general-information), [Commiphora 연구](https://doi.org/10.2985/0007-9367-84.3.140)

여행자나무는 마다가스카르 원산이지만 이것만으로 특정 서부 바오밥 숲과 동일한 식생 군집이라는 뜻은 아니다. 현재 맵은 섬의 식생을 압축한 게임용 구성이다. 남부 가시숲의 Alluaudia/Didierea를 추가할 경우 별도 건조 구역을 먼저 설계하고, 우림 식생과 무조건 섞지 않는다.

### 무인도 — 해변에서 안쪽 숲으로 이어지는 층

| 식물 | 화면에서 구별할 형태 | 배치 |
|---|---|---|
| 코코넛야자 | 휜 줄기, 굵고 단순한 깃잎, 코코넛 | 해변 뒤와 바람에 열린 가장자리 |
| 판다누스 Pandanus형 | 짧게 갈라진 줄기, 지주뿌리, 방사형 긴 띠잎 뭉치 | 해안 뒤쪽 군락 |
| 바다아몬드 Terminalia catappa형 | 세 층으로 펼쳐진 넓은 잎 수관, 일부 붉은 잎 | 안쪽의 그늘진 혼합 숲 |
| 황근/해변 관목 | 둥근 잎 관목과 노란 꽃 | 모래에서 숲으로 넘어가는 띠. **후속 제작 후보** |
| 갯메꽃류 Ipomoea pes-caprae | 모래 위로 기는 낮은 줄기와 잎 | 백사장 뒤쪽. **후속 제작 후보** |

열대 해안에는 야자 외에도 판다누스·바다아몬드·황근 등 다양한 목본이 있으며, 모래에 가까운 곳에는 낮은 덩굴/초본층이 생긴다. 모든 섬의 종 구성이 같다는 뜻은 아니다. [NParks 해안 식생](https://www.nparks.gov.sg/-/media/sbg/flora-of-singapore/volume-1-introduction/1%2C-d-%2C5_vegetation_lr.pdf), [바다아몬드](https://heritagetrees.nparks.gov.sg/ht-2020-316/), [황근](https://www.nparks.gov.sg/florafaunaweb/flora/2/9/2954), [NTBG 판다누스 해안 표본](https://ntbg.org/database/herbarium/detail/PTBG1000031911)

## 구현 규칙

1. 각 신규 맵에 **서로 다른 실루엣의 큰 식물 3종**을 실제 파일로 연결한다. 동일 이미지를 3번 로딩하거나 색/크기만 바꾼 것은 3종이 아니다.
2. 수종은 물길 거리·해안 거리·건조 통로·연속적인 군락 함수로 선정한다. 모든 곳에서 동일 확률로 산포하지 않는다.
3. 위의 배치 비율은 게임 가독성을 위한 선택이다. 실제 숲의 수종 비율을 조사했다고 주장하지 않는다.
4. 나무뿐 아니라 땅 덮개와 환경 생물의 배치도 수분·해안에 맞춘다. 미제작 식물을 기존 고사리의 이름만 바꿔 대신하지 않는다.
5. 2D 카툰 검수: 실루엣 축소 뷰에서 먼저 구별되어야 한다. 잎 하나하나를 빽빽하게 그리기보다 큰 잎 덩어리 안의 단계 명암을 쓴다.
6. 새 맵을 완성으로 부르기 전에 종별 실배치 수와 서로 다른 런타임 자산 경로, 게임 크기 화면을 확인한다.
