## 스킬별 표현과 판정

| 스킬 | 적용한 표현 | 유지한 판정 |
|---|---|---|
| 박쥐 떼 | 보라색 날개막·몸체, 6프레임 날갯짓, 궤도 접선 방향 회전 | 사거리 안의 생존 몬스터만 골라 한 마리씩 급강하 |
| 가시 오라 | 두 줄로 엮인 덩굴, 바깥쪽으로 굽은 큰 가시, 틱 순간 밝아지는 테두리 | 플레이어 중심 전체 범위 틱. 장식 끝은 실제 반경 안에 위치 |
| 까마귀 습격 | 피격점의 즉시 섬광, 푸른 깃털의 까마귀 3마리가 부채꼴로 이탈 | 620 안의 **가장 먼 생존 몬스터** 저격. 즉시 피해·주변 피해 유지 |
| 덩굴 채찍 | 가시 달린 굽은 덩굴, 부채꼴 접촉 섬광, 휘두른 뒤 잔상 | 가장 가까운 생존 몬스터 방향·반각 0.75. 몬스터가 없으면 시전 대기 |
| 부메랑 도끼 | 금속 날·나무 손잡이 스프라이트 회전, 최대 5개 위치 잔상, 귀환 시 금빛 흔적 | 가장 가까운 생존 몬스터를 향해 발사. **왕복 각 1회 타격** |
| 씨앗 지뢰 | 나무껍질 씨앗·잎, 퓨즈에 따라 발아 균열·떨림·빛 증가, 폭발 후 껍질·잎·흙 비산 | 가장 가까운 생존 몬스터 방향에 설치. 1.1초 뒤 한 번 폭발 |
| 번개 사슬 | 흰 중심·청색 외곽의 꺾인 전류, 곁가지와 각 피격점 섬광 | 생존 몬스터 사이만 260 이내 점프. 실제 타격 좌표만 연결하고 중복 타격 없음 |

까마귀·채찍·번개는 기존 판정이 즉시 발생한다. 준비 모션을 새로 붙여 판정이 늦게 일어나는 것처럼 속이지 않는다. 접촉은 첫 프레임에 표시하고 뒤따르는 새의 이탈·채찍 스윙·전류 흔들림은 잔류 표현이다. 가시 오라의 밝기는 실제 `auraPulse`에 연결한다. 박쥐는 아무것도 맞히지 않은 주기에 가짜 피격 섬광을 내지 않는다.

직접 표적을 고르는 공용 스킬은 나무를 대체 표적으로 쓰지 않는다. 생존 몬스터가 없으면 짧게 기다렸다 다시 탐색한다. 부메랑·지뢰처럼 범위가 있는 공격은 몬스터를 향해 발동한 뒤 경로 또는 폭발 안의 나무에 부수 피해를 줄 수 있다.

부메랑은 출발 구간의 끝점 충돌 처리까지 마친 다음 귀환용 `hitSet`을 비운다. 같은 구간에서의 연속 중복 타격은 계속 막는다.

## 자산·제작 규격

| 고정 모델 | 프레임 셀 | 프레임 | 실제 팔레트 색 수 | 월드 너비 |
|---|---|---|---|---|
| 박쥐 | 192×128 | 6 | 88 | 48 |
| 까마귀 | 224×160 | 6 | 89 | 70 |
| 도끼 | 160×160 | 1 | 92 | 49 |
| 씨앗 | 128×160 | 1 | 111 | 31 |

- 원본과 정확한 생성 프롬프트: `assets/fx/supplement/concepts/*-v1.png`, `prompts-v1.json`. 원본은 보존한다.
- 생성 원화는 고정 모델이다. `scripts/build_supplement_sprites.py`가 기존 GPU 픽셀 재질 베이크를 사용해 최종 아틀라스와 `src/supplement_sprite_catalog.lua`를 만든다. 프레임별 독립 생성은 하지 않는다.
- 새의 중심 몸통은 고정하고 양쪽 날개만 접히도록 공통 베이크에 **선택적 `flightRig`**를 추가했다. 기본값 0은 기존 나무·몬스터의 제작 동작을 바꾸지 않는다. 이전 자산을 재생성하지 않았다.
- 자산별 고유 팔레트, 재질별 16단계 램프. 최종 스프라이트 알파는 0/255이고 런타임 필터는 `nearest`다. 회전 잔상의 투명도는 렌더 단계에서만 적용한다.
- 절차적 FX는 `assets/shaders/supplement-fx.glsl`의 7개 분기. 그리드는 **월드 크기 × 3.2**로 계산하며 색은 16단계, 알파는 15단계로 양자화한다. 반경을 키울 때 원생 그리드도 함께 커진다. 블러나 저해상도 아이콘 확대를 사용하지 않는다.
- 초록 가시/덩굴, 청백 번개, 황갈색 씨앗, 은색 도끼를 구분한다. 모든 스킬을 같은 색·같은 원형 충격파로 만들지 않는다.

## 상태·성능 경계

`SupplementArt.update`는 전투 업데이트에서만 시간을 전진시킨다. 그리기는 HP, 판정, 난수, 수명, 위치를 수정하지 않는다. 일시정지 중 `love.timer.getTime()`이 늘어도 이펙트는 진행하지 않는다. 이전 셰이더와 색상은 복원한다. 스킬이 없으면 자산을 지연 로드하지 않고 즉시 반환한다.

짧은 시각 이벤트는 최대 64개, 도끼당 잔상은 최대 5개다. 수명 종료 시 제거하며 스테이지 전환 때 피격 잔상들을 비운다. 큰 텍스처/셰이더는 프레임마다 새로 생성하지 않는다. 테스트 장면의 동시 드로우 수는 [검증 JSON](previews/supplement-fx-verification.json)에 기록한다. 이것은 실제 플레이의 FPS 벤치마크가 아니다.

## 검증

```text
python scripts/headless_lua.py scripts/verify_supplement_fx.lua
python scripts/build_supplement_sprites.py
python scripts/render_supplement_fx.py
```

베이크·렌더는 Pillow, NumPy, ModernGL과 OpenGL 드라이버가 필요하다. 헤드리스 Lua는 기본적으로 `C:\Program Files\LOVE\lua51.dll`을 사용하며 `LOVE_LUA_DLL`로 바꿀 수 있다. 어느 명령도 LÖVE 게임 창을 실행하지 않는다.

- 전용 회귀 검사: 7종 타깃·범위·타이밍, 귀환 및 끝점 타격, 이벤트 정리, 실제 PNG 로드, nearest, 렌더 순수성, 셰이더/색 복원, 일시정지 확인.
- GPU: AMD Radeon(TM) Graphics에서 실제 런타임 셰이더 컴파일·200프레임 렌더. 각 개별 효과의 동작 변화와 동시 사용 화면 확인.
- 전체 헤드리스 회귀 검사를 통과해야 하며, 공용 스킬 검사는 몬스터 전용 표적 선택·왕복·퓨즈·연쇄·렌더 순수성을 함께 확인한다.
- 게임 창을 실행한 수동 플레이 검증은 하지 않았다.
