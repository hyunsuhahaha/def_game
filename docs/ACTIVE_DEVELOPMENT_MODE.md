# 현재 활성 개발 모드

## 활성 범위

2026-09-02 기준 로비의 주 진입점은 **벌목 기록 모드(`score_attack`)**와 **무한 디펜스(`defense`)** 두 개다.

디펜스는 기록 모드의 무기·영구 연구·동료를 공유하되 숲 공급 규칙만 다르다.

- 원형 나무 띠 하나가 한 단계다. 시작 화면에는 1~4단계 띠가 동시에 있다.
- 디펜스 맵은 원본 온대 숲의 160%(`5120×3200`, 플레이 영역 `3840×2240`)로 확장한다.
- 이전 띠를 제거했는지와 무관하게 1.25초마다 다음 단계 띠가 화면 밖의 외곽 반경 1080에서 계속 유입된다.
- 띠마다 96그루이며 기본 체력은 기존의 2배, 이후 단계마다 선형으로 25%씩 더 오른다.
- 모든 띠는 초당 48 월드 단위로 먼 외곽에서 중앙을 향한다. 반경 110 중앙 방어선에 한 그루라도 닿으면 패배한다.
- 디펜스에서는 목재 드롭을 생성하지 않는다. 나무 1킬을 즉시 재화 1로 계산한다.
- 승리·고정 제한 시간·과밀 종료는 없다. 살아 있는 동안 단계가 무한히 증가한다.

- 활성 일반 나무 6그루에서 시작한다.
- 활성 일반 나무가 허용량에 닿으면 종료한다.
- 저장된 영구 재생 단계에서 시작하며, 0그루 달성 시 다음 단계가 즉시 해금·저장된다.
- 재생 속도는 `0.14 × 1.75^(단계-1) × 2^(현재 단계 플레이 시간/20초)`, 나무 HP는 `1.03^(단계-1)` 배율을 사용한다. 같은 단계에 머물러도 공급량이 20초마다 두 배가 되며, 0그루 달성 또는 40초 뒤 세계수 처치로 승급하면 단계 시간 배율이 초기화된다. 난도 상승은 체력보다 재생 물량이 주도한다.
- 멧돼지·다람쥐를 포함한 일반 몬스터는 기록 모드에서 생성하지 않는다. 난도는 재생 물량과 과밀로만 만든다.
- 나무에서 얻은 목재는 벌목 점수와 수종별 연구 코인 정산에만 사용한다. 인게임 XP·레벨업·강화 3택은 없다.
- 무기·동료·운영 성장은 로비 영구 연구에서만 구매한다. 일반 작전의 카드·융합 코드는 보존하지만 기록 모드 후보 풀에는 넣지 않는다.
- 메타 진행은 `작업 → 정산 → 기록전 영구 연구 → 즉시 다음 작업`으로 연결한다. 상세 기준은 `docs/SCORE_ATTACK_META_LOOP.md`다.
- 로비 `P` 연습장도 같은 `score_attack` 런타임을 쓴다. 단, 시간·과밀·개체 수 상한·0그루 승급·세계수를 끄고 나무를 계속 생성하는 무한 테스트장으로 변형한다. 보유 특성과 세이브를 건드리지 않는 임시 전체 만렙 사이를 선택할 수 있다.
- `F10` 개발자 도구에는 활성 영구 연구를 실제 가격이 싼 순서로 채우는 `10%~100%`(10% 단위) 저장 프리셋이 있다. 선행 조건을 지킨 정상 연구망을 만들며, 진행 중인 판에는 재시작 뒤 적용된다.
- 같은 메뉴의 `튜토리얼 실행`은 저장 상태를 무시하고 핵심 안내를 즉시 재생한다. 로비에서 실행하면 별도 기록전으로 들어가며 실제 첫 판/두 번째 판 횟수와 튜토리얼 완료 기록을 바꾸지 않는다. 사용하지 않는 런 자원 지급 및 다음 런 레벨 자동·수동 버튼은 메뉴에서 제거했다.

## 의도적으로 비활성화한 범위

다음 코드는 삭제하거나 폐기하지 않았다. 현재 프로토타입의 핵심 루프를 검증하기 위해 **로비 진입점만 닫았다.**

- 일반 1-1~4-4 작전과 세계수·지역 보스 전투
- 작업자 선택과 흡연자 외 캐릭터 런
- 지구본 맵 선택과 현장 브리핑
- 일반 스테이지의 공용 카드·융합·시너지 성장
- 러시와 기타 이전 모드
- 다른 작업자의 영구 특성 데이터와 저장 기록

관련 구현은 `src/game.lua`, `src/clearcut_mode.lua`, `src/clearcut_map_select.lua`, `src/rush_mode.lua`, `src/character_traits.lua`에 보존한다. 일반 작전의 예전 스킬 샌드박스 API도 회귀 검증을 위해 남겨 두지만, 로비 연습 진입은 현재 기록 모드만 사용한다.

## 다른 에이전트 작업 규칙

1. 사용자가 명시적으로 요청하기 전에는 비활성 모드를 로비에 다시 노출하지 않는다.
2. 비활성 코드를 정리 대상으로 간주해 삭제하거나 대규모 리팩터링하지 않는다.
3. 기록 모드의 수치·연구·UI를 바꾸면 `docs/SMOKER_SCORE_ATTACK_MODE.md`와 `docs/character_dossier.html`을 함께 갱신한다.
4. 기존 모드 테스트 실패를 기록 모드 전환의 당연한 결과로 무시하지 않는다. 코드는 보존되어야 하므로 회귀 테스트를 계속 통과시킨다.
5. 로비에서 Enter/Space/M은 기록 모드, D는 디펜스를 시작한다. 일반 작전 함수는 코드·테스트용으로만 남는다.

## 복구 지점

향후 일반 작전을 다시 활성화할 때는 `src/lobby.lua`의 `ACTIVE_DEVELOPMENT_MODE`와 의도적 비활성 주석을 기준으로 진입 버튼을 복구한다. `Game:startClearcut`, 캐릭터 선택, 지구본, 브리핑 코드는 이미 유지되어 있으므로 새로 만들지 않는다.
