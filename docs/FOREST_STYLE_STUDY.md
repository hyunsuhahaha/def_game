## 사용자 기준

뱀파이어 서바이버즈 같은 전투 가독성과 단순한 픽셀 실루엣을 바탕으로, 픽셀 재질의 완성도와 동작의 역동성을 조금 더 높인다. 고밀도 픽셀 품질과 복잡한 장식·사실적 묘사는 별개다.

- 나무: 잎과 잔가지의 노이즈를 줄이고 큰 수관 덩어리, 굵은 줄기와 뿌리, 종류별 명확한 실루엣으로 정리한다.
- 몬스터: 기존 작은 다람쥐·멧돼지·식물 등의 비율과 정체성을 유지한다. 표정·명암·움직임을 개선하되 복잡한 새 판타지 캐릭터로 대체하지 않는다.
- 역동성: 장식을 늘리는 대신 공격 준비·접촉·회수, 기울기, 반동, 짧은 먼지와 피격 반응에서 만든다.
- 배경: 차분한 바닥과 접지 그림자를 사용해 이동 중인 캐릭터와 적이 먼저 읽히도록 한다.

## 화면 시안

[`previews/forest-vs-style-study-v1.png`](previews/forest-vs-style-study-v1.png)는 내장 ImageGen으로 사용자 스크린샷을 편집한 **승인된 방향 목업**이다. 실제 엔진 캡처나 최종 자산 검증 결과가 아니다.

프롬프트 요지: 같은 카메라·배치·플레이어·기존 몬스터 정체성·체력바·조준원을 유지한다. 나무를 큰 잎 덩어리와 단순한 줄기의 카툰 픽셀 스프라이트로 바꾼다. 사실적인 잎·잔가지 묘사를 약 70% 줄이고 단계별 명암과 미세 픽셀 클러스터를 쓴다. 기존 몬스터는 소폭 개선하고 멧돼지에 가벼운 돌진 자세와 먼지를 준다. 바닥 대비를 줄인다. 실사풍·장식적인 판타지·매끈한 페인팅·거친 저해상도 블록·새 UI 문구는 제외한다.

미채택 몬스터 원화와 파생 아틀라스는 [`assets/enemies/README.md`](../assets/enemies/README.md)에 구분했다. 그 파일들은 보존하고, 새로 만든 `arcade/*-v3.png`만 게임에 연결했다.
