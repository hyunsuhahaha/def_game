# 로비 배경음 — 파일 없는 절차적 음악

로비에는 재생/정지 버튼과 트랙 이름 셋이 붙은 플레이어 UI가 먼저 있었고 **소리는 없었다.** 파형 애니메이션도 `math.sin`으로 그린 가짜였다. 이 문서는 그 자리에 실제로 소리를 넣은 방식을 남긴다.

## 오디오 파일을 쓰지 않는 이유

이 저장소에는 `.wav`/`.ogg`가 하나도 없다. 효과음 13종은 [`src/feedback.lua`](../src/feedback.lua)가 런타임에 샘플을 계산해서 만든다. 배경음도 같은 방식([`src/lobby_audio.lua`](../src/lobby_audio.lua))을 쓴다 — 용량도 라이선스도 붙지 않고, 로비가 UI로 내세우던 "픽셀 오디오"라는 설정과도 맞는다.

## 트랙

| 트랙 | BPM | 길이 | 진행 | 성격 |
|---|---:|---:|---|---|
| FOREST DAY / LOOP 07 | 96 | 10.00s | Am–F–C–G | A 단5음 멜로디 + 가벼운 하이햇 |
| RIVER LINE / LOOP 03 | 84 | 11.43s | Dm–B♭–F–C | 끊기지 않는 8분음표 아르페지오 + 물소리 바닥 |
| OWL SHIFT / LOOP 11 | 66 | 14.55s | Em–Cmaj7–Am–B | 긴 패드 + 두 음이 떨어지는 부엉이 동기 2회 |

전부 4마디 루프다. 멜로디에 **단5음(pentatonic)** 을 쓰는 이유는 반음이 없어 어느 화음 위에 얹어도 어긋나지 않기 때문이다.

## 두 가지 기술적 선택

**루프 이음매는 감아서(wrap) 잇는다.** 마디 끝을 넘긴 음의 꼬리를 버퍼 앞쪽에 더하면 마지막 샘플의 다음이 그 음의 실제 다음 샘플이라 파형이 이어진다. 페이드로 자르면 루프마다 소리가 숨을 쉬고, 그냥 자르면 딸깍거린다. 실측 이음매 단차는 0.0005 이하다.

**사각파는 홀수 배음 셋으로만 만든다.** 진짜 사각파는 배음이 끝없이 올라가 나이퀴스트(11,025Hz)에서 접혀 들어와 금속성 잡음이 된다. 1·3·5차만 더하면 사각파의 성격은 남고 대역은 제한된다.

## 소리는 눈으로 검수할 수 없다

이 저장소의 그래픽 규칙은 오프스크린 렌더로 **눈으로** 확인하라고 요구한다. 소리에는 그 대응물이 없다. 그래서 역할을 나눈다.

```bash
python scripts/headless_lua.py scripts/verify_lobby_audio.lua
```

수치 검사가 잡는 것 — 무음, 클리핑, DC 오프셋, 루프 이음매 딸깍임, 실행마다 달라지는 렌더, 재생 상태 기계(트랙 교체 시 앞 곡이 겹치는지, 작전 중에 멎는지, 소리 장치가 없을 때 매 프레임 재합성하는지).

```bash
python scripts/headless_lua.py scripts/export_lobby_audio.lua
```

같은 코드로 `docs/previews/lobby-*.wav` 를 뽑는다. **곡이 괜찮은지는 이 파일을 사람이 들어야 안다.** 검사를 통과했다는 것과 들을 만하다는 것은 다른 문제다.

## 고치는 곳

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 화음 진행 | `TRACKS[n].chords` — `{베이스 반음, {패드 화음 반음들}}`, A1(55Hz) 기준 |
| 멜로디 | `TRACKS[n].lead` — `{박, 반음, 길이(박)}` |
| 템포·루프 길이 | `TRACKS[n].bpm` / `.beats` |
| 곡별 음량 | `TRACKS[n].gain` (봉우리 기준) |
| 전체 음량 | `LobbyAudio:source` 의 `setVolume` |
| 음색 | `square3`/`warm` 의 배음 비율, `addNote` 의 엔벨로프 |

수치를 바꾸면 `export_lobby_audio.lua` 를 다시 돌려 wav 를 갱신한다.
