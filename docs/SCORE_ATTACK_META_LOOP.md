# 벌목 기록 모드 메타 루프 v1

## 핵심 반복

**나무 6그루에서 시작해 목재로 런 안의 스킬을 고르고, 과밀로 끝난 작업의 기록과 정산 목재로 다음 작업의 영구 성능을 높인다.**

1. 활성 나무 6그루에서 작업을 시작한다.
2. 직접 착화하고, 목재 경험치가 찰 때마다 스킬 카드 3개 중 하나를 고른다.
3. 산림 공급이 점점 빨라져 현재 빌드의 벌목량을 압박한다.
4. 활성 나무가 허용량에 닿으면 즉시 종료한다.
5. 버틴 시간, 총 벌목, 최고 생산력, 도달 레벨을 정산한다.
6. 영구 연구를 구매하고 다음 작업을 시작한다.

```mermaid
flowchart LR
    A[나무 6그루] --> B[벌목·목재 경험치]
    B --> C[레벨업 스킬 3택]
    C --> D[산림 공급 가속]
    D --> E[과밀 종료]
    E --> F[정산·영구 연구]
    F --> A
```

## 두 성장 층

| 성장 | 유지 범위 | 역할 |
|---|---|---|
| 목재 경험치 | 현재 런 | 흡연자 전용 스킬 카드, 3레벨 분기, 6레벨 진화 |
| 정산 목재·연구 | 런 사이 | 첫 착화, 투척 성능, 나무 허용량 |

한 그루의 목재는 현재 런 경험치에 들어가면서 실제 벌목량으로도 기록된다. 런 중 별도 자동화 설비를 구매하거나 `Z/X/C/V`로 소비하지 않는다. 업적 포인트는 업적 전용 재화로 분리한다.

## 선택 구조

초반에는 직접 투척, 착화·확산, 건초, 폐유, 도넛 중 무엇을 먼저 올릴지 선택한다. 공용 전투 스킬은 현재 카드 풀에서 제외하고, 직접 줍는 동선을 줄여 주는 아기 운반 로봇만 공용 유틸리티 카드로 허용한다. 3레벨의 작동 방식 분기와 한정된 카드 기회가 매 판의 차이를 만들고, 후반에는 선택한 엔진이 늘어난 산림 공급을 상대로 폭주해야 한다.

영구 연구는 런의 시작 안정성과 허용량을 높이지만 런 내부 빌드를 대신 완성해주지 않는다. 따라서 연구가 쌓여도 매 판 목재를 모아 카드 선택을 다시 해야 한다.

## 목표 런 길이

| 진행 구간 | 목표 런 길이 |
|---|---:|
| 첫 1~2회 | 15~30초 |
| 3~5회 | 35~60초 |
| 6~10회 | 60~120초 |
| 중반 | 2~4분 |
| 후반 | 4~6분 |

강한 빌드가 오래 버티려면 나무 공급도 벌목량을 따라야 한다. 종료 원인은 재료 부족이 아니라 벌목 엔진이 산림 증가를 더는 감당하지 못한 결과여야 한다.

## 완료 판정

- 첫 목재 획득부터 경험치가 오르는 것이 보인다.
- 요구 경험치를 채우면 카드가 정확히 3장 중앙에 뜬다.
- 선택하지 않은 동안 전투가 진행되지 않는다.
- 자동화 구매 HUD와 단축키가 남아 있지 않다.
- 현재 직업이 없는 공용 전투 카드는 드래프트에 나타나지 않는다. 예외는 목재 회수 전용 아기 운반 로봇 하나다.
- 3레벨 분기, 6레벨 진화, 시너지 표시는 일반 작전과 동일하게 작동한다.
- 결과에서 도달 레벨과 최고 생산력을 확인할 수 있다.
