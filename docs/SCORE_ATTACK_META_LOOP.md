# 벌목 기록 모드 메타 루프 v1

## 핵심 반복

**저장된 재생 단계에서 나무 6그루로 시작해 목재로 런 안의 운영 설비를 고르고, 영구 전투 연구로 현재 단계의 벽을 넘는다.**

1. 활성 나무 6그루에서 작업을 시작한다.
2. 직접 착화하고, 목재 경험치가 찰 때마다 비전투 운영 카드 3개 중 하나를 고른다.
3. 산림 공급은 저장된 영구 재생 단계에서 시작한다. 현재 나무를 0그루로 만들면 다음 단계가 즉시 저장되고, 0.86초 단계 상승 연출 중 전투가 멈춘 뒤 6그루가 순차 발아한다. 다음 판도 저장된 단계에서 시작한다.
4. 재생 속도는 `0.14 × 1.75^(단계-1) × 2^(플레이 시간/60초)`, 나무 HP는 `1.03^(단계-1)`로 올라간다. 최근 벌목량을 따라가는 보정은 사용하지 않지만 같은 단계에서도 시간 압력이 60초마다 두 배가 되어 무한 유지할 수 없으며, 난도는 체력보다 재생 물량으로 빠르게 상승한다.
5. 목재 경험치는 비전투 운영 카드 3택만 열며, 로비에서는 흡연자의 세부 전투 특성을 성장시킨다.
6. 활성 나무가 허용량에 닿으면 즉시 종료한다.
7. 버틴 시간, 총 벌목, 최고 재생 단계와 운영 레벨을 정산한다.
8. 영구 전투 연구를 구매하고 저장된 재생 단계에서 다음 작업을 시작한다.

```mermaid
flowchart LR
    A[나무 6그루] --> B[벌목·목재 경험치]
    B --> C[운영 카드 3택]
    C --> D[0그루 · 재생 단계 영구 상승]
    D --> E[과밀 종료]
    E --> F[정산·영구 연구]
    F --> A
```

## 두 성장 층

| 성장 | 유지 범위 | 역할 |
|---|---|---|
| 목재 경험치 | 현재 런 | 회수·조림·허용량·안전관리 운영 카드 |
| 성과 포인트 특성 | 런 사이 | 투척·착화·확산·연소 세부 수치와 나무 허용량 |
| 재생 단계 | 영구 | 다음 런의 시작 공급 속도와 완만한 나무 HP 보정 |

한 그루의 목재는 현재 런 경험치에 들어가면서 실제 벌목량으로도 기록된다. 런 중 별도 자동화 설비를 구매하거나 `Z/X/C/V`로 소비하지 않는다. 업적 포인트는 업적 전용 재화로 분리한다.

## 선택 구조

전투 성능은 로비에서 투척 거리·착화 반경·착화 확률·확산량·흡연/비행/연소 속도처럼 작은 특성을 갈래별로 구매한다. 특정 인게임 스킬 레벨을 영구 연구 하나로 통째로 지급하지 않는다. 런에서는 아기 로봇, 탐지 안테나, 작업장 확장, 조림 구획, 목재 선별기, 안전 관리 장치만 선택한다. 드래프트의 전투 카드는 무기 중립 수치(피해·범위·사거리·공격속도)만 쓴다. 무기 전용 수치와 해금은 영구 연구에만 둔다.

영구 연구는 현재 재생 단계의 화력 벽을 넘기고, 매 판 초기화되는 운영 카드는 그 화력에 목재 회수·공급 위치·과밀 여유를 맞춘다. 같은 영구 전투 상태라도 어떤 운영 설비를 먼저 확보했는지에 따라 런의 동선과 안정성이 달라진다.

## 목표 런 길이

| 진행 구간 | 목표 런 길이 |
|---|---:|
| 첫 1~2회 | 15~30초 |
| 3~5회 | 35~60초 |
| 6~10회 | 60~120초 |
| 중반 | 2~4분 |
| 후반 | 4~6분 |

강한 빌드는 0그루를 달성해 다음 영구 단계로 올라간다. 종료 원인은 나무 한 그루가 지나치게 단단해서가 아니라, 저장된 단계의 재생 물량을 더는 따라잡지 못한 결과여야 한다.

## 완료 판정

- 첫 목재 획득부터 경험치가 오르는 것이 보인다.
- 요구 경험치를 채우면 카드가 정확히 3장 중앙에 뜬다.
- 선택하지 않은 동안 전투가 진행되지 않는다.
- 자동화 구매 HUD와 단축키가 남아 있지 않다.
- 기록 모드 드래프트에는 운영 카드 여섯 장과 무기 중립 전투 카드 네 장만 나타난다. 무기별 전용 수치는 영구 연구에만 둔다.
- 전투 카드·3레벨 분기·6레벨 진화·융합 코드는 일반 작전과 연습장에 보존한다.
- 결과에서 운영 레벨, 최고 재생 단계와 최고 생산력을 확인할 수 있다.
