# 벌목 기록 모드 메타 루프 v1

## 한 문장 목표

**짧게 과밀로 끝난 작업에서 목재를 정산하고, 눈에 보이는 설비 하나를 강화한 뒤, 한 번 더 오래 버티기 위해 즉시 다음 작업을 시작한다.**

이 문서는 현재 활성 개발 모드인 흡연자 `score_attack`의 `게임 → 강화 → 게임 → 강화` 반복 구조를 정의한다. 일반 캠페인과 다른 작업자 코드는 삭제하지 않고 비활성 상태로 보존한다.

## 한 사이클

1. `벌목 기록 시작`을 누르면 빈 땅에서 작업을 시작한다.
2. 시간과 회사 등급에 따라 나무가 자동으로 증가한다.
3. 플레이어는 직접 착화하고, 런 안에서 현장 목재로 자동화 설비를 산다.
4. 활성 나무가 허용량에 닿으면 즉시 작업을 종료한다.
5. 0.35초 정지 후 이번 기록과 정산 목재를 짧게 보여준다.
6. 로비로 돌아가지 않고 기록전 영구 연구 화면을 자동으로 연다.
7. 강조된 2~4개 인접 연구 중 원하는 것을 구매한다.
8. `다음 작업`을 누르면 같은 캐릭터로 즉시 새 런을 시작한다.

`Esc → 로비`는 별도 이탈 행동이다. 일반적인 재도전 흐름에 로비, 작업자 선택, 지구본, 브리핑을 끼우지 않는다.

```mermaid
flowchart LR
    A[빈 땅에서 작업 시작] --> B[벌목·현장 자동화]
    B --> C[나무 과밀로 종료]
    C --> D[정산 목재 획득]
    D --> E[인접 영구 연구 구매]
    E --> F[회사 등급·숲 압력 자동 반영]
    F --> A
```

## 재화는 두 층으로 분리

| 재화 | 유지 범위 | 사용처 |
|---|---|---|
| 현장 목재 | 현재 런 | 자동 꽁초 투척기, 건초 공급기, 폐유 펌프, 산림 증설 |
| 정산 목재 | 영구 | 최초 착화, 투척 성능, 자동화 기반, 부지 허용량 연구 |

나무 한 그루를 베면 현장 목재와 정산 예정 목재가 함께 오른다. 현장 목재는 런 종료 시 사라지고, 소비 여부와 무관하게 실제 벌목으로 얻은 양만 정산 목재가 된다. 시작 목재, 환불, 개발자 지급분은 정산에 포함하지 않는다.

업적 포인트는 업적 전용으로 남긴다. 활성 기록전 연구의 기본 결제 수단을 업적 포인트와 섞지 않는다.

## 종료 화면과 강화 화면의 연결

종료 화면은 실패 확인 창이 아니라 `이번 작업 정산`이다.

- 버틴 시간
- 벌목한 나무
- 최고 초당 벌목량
- 정산 목재
- 이전 최고 기록 대비 증가량

숫자가 0.9초 동안 빠르게 합산된 뒤 `연구 선택` 버튼이 켜진다. Enter 또는 클릭으로 같은 화면이 밀려나며 연구망이 열린다. 별도 로딩, 전투 실패 문구, 긴 결과 통계표를 넣지 않는다.

연구 구매 뒤 가장 큰 버튼은 `다음 작업`이다. 구매 가능한 연구가 남아 있어도 플레이어가 저장할 수 있지만, 초반 8회는 정상적인 플레이 한 번의 정산으로 최소 한 개의 강조 연구를 살 수 있게 비용을 맞춘다.

## 강화를 미루는 저압 파밍 방지

회사 등급은 구매한 연구 수가 아니라 **누적 정산 목재**로 자동 상승한다. 목재를 쓰지 않고 저장해도 더 낮은 숲에 머무를 수 없다.

| 회사 등급 | 누적 정산 목재 | 기본 공급 | 기본 허용량 | 새로 보이는 변화 |
|---:|---:|---:|---:|---|
| 0 수습 | 0 | 0.20그루/초 | 6 | 어린 활엽수 |
| 1 작업반 | 30 | 0.32그루/초 | 8 | 일반 활엽수, 굵은 밑동 |
| 2 현장팀 | 100 | 0.55그루/초 | 12 | 소나무·자작나무 혼합 |
| 3 벌목소 | 300 | 0.90그루/초 | 18 | 대형 수목, 빠른 새싹 |
| 4 지사 | 900 | 1.60그루/초 | 28 | 군락 재생, 단단한 수종 |
| 5 본부 | 2,500 | 3.00그루/초 | 42 | 화면 단위 산림 증식 |
| 6 과부하 | 7,000 | 5.50그루/초 | 64 | 대량 재생과 고급 수종 |

각 런 안에서는 기본 공급량이 30초마다 약 1.35배 증가한다. 사용자가 산림 증설을 구매하지 않아도 반드시 압력이 상승하고 작업은 끝난다. 최근 벌목량을 무조건 108%로 따라가는 현재 방식은 재료 고갈을 막는 짧은 보충 안전장치로만 축소한다.

회사 등급 상승은 다음 런 시작 전에 자동 적용하며 되돌릴 수 없다. 등급이 오를 때 공급량만 숫자로 바꾸지 말고 새 수종, 더 많은 동시 발아, 배경의 적재 목재와 설비 변화로 화면 밀도 상승을 보여준다.

## 영구 연구망 구성

한 번에 모든 연구를 나열하지 않는다. 현재 구매할 수 있는 인접 노드 2~4개만 강하게 표시한다.

### 착화 계통

- 최초 착화 준비시간 감소
- 착화 확률 증가
- 연소 피해 증가
- 기계식 연속 점화 해금

### 투척 계통

- 재장전 감소
- 사거리 증가
- 꽁초 동시 투척
- 줄꽁초 또는 폭죽 계통 해금

### 자동화 계통

- 시작 목재 증가
- 자동 꽁초 투척기 시작 배치
- 건초·폐유 설비 기본 단계 증가
- 설비 구매 비용 감소

### 부지 계통

- 나무 허용량 증가
- 고급 수종 목재 가치 증가
- 산림 증설 위험 보상 증가
- 과밀 경고 유예가 아닌 물리적 적재 공간 확장

수치 연구 2~3개 뒤에는 반드시 화면과 작동 방식이 달라지는 연구를 둔다. 같은 `피해 +5%` 노드를 길게 반복하지 않는다.

## 선택은 단순하지만 순서는 달라야 함

영구 연구는 궁극적으로 모두 살 수 있지만, 가격 때문에 당장 어느 계통을 먼저 여는지가 달라진다.

- 착화를 먼저 사면 첫 30초가 안정적이다.
- 투척을 먼저 사면 직접 조작 화력이 빠르게 오른다.
- 자동화를 먼저 사면 다음 런의 중반 생산력이 오른다.
- 부지를 먼저 사면 실수 허용량이 늘지만 벌목 속도는 그대로다.

초반 연구 비용은 `8 / 12 / 16`, 다음 고리는 `24 / 36 / 52`, 작동 변화 노드는 `70~110` 범위를 시작 기준으로 삼는다. 실제 한 런 정산량의 0.6~1.3배에 다음 일반 노드가 오도록 조정하고, 핵심 해금만 2~3회의 정산을 요구한다.

## 목표 런 길이

| 진행 구간 | 목표 런 길이 | 플레이 감정 |
|---|---:|---|
| 첫 1~2회 | 15~30초 | 바로 끝나지만 첫 연구를 살 수 있음 |
| 3~5회 | 35~60초 | 직접 착화와 첫 자동화 선택 |
| 6~10회 | 60~120초 | 선택한 연구 순서의 차이가 보임 |
| 중반 | 2~4분 | 자동화가 화면을 장악하기 시작 |
| 후반 | 4~6분 | 대량 생성과 대량 벌목이 충돌 |

첫 완주 목표는 회사 등급 6에서 6분 생존 또는 단일 런 10,000그루 벌목 중 먼저 달성한 조건으로 둔다. 달성 뒤에는 같은 구조의 무한 기록전을 연다.

## 구현 순서

1. 기록 모드 정산 목재 저장과 개발자 지급분 제외
2. 결과 → 영구 연구 → 다음 작업의 무로딩 연결
3. 누적 정산 목재 기반 회사 등급과 강제 산림 공급 곡선
4. 연구 비용 재조정과 첫 8회 최소 1구매 검증
5. 회사 등급별 수종·발아·배경 밀도 변화
6. 15초~6분 목표 런 자동 시뮬레이션과 실제 플레이 조정

## 완료 판정

- 첫 런 종료 후 두 번 이하의 입력으로 연구 화면에 도달한다.
- 첫 정상 런에서 구매할 수 있는 연구가 최소 하나 있다.
- 연구 구매 후 한 번의 입력으로 다음 런이 시작된다.
- 정산 목재를 쓰지 않아도 회사 등급과 산림 압력은 상승한다.
- 어떤 영구 연구도 게임 종료 조건을 제거하지 않는다.
- 후반 화면의 나무 수종·밀도·자동화가 첫 화면과 즉시 구분된다.
