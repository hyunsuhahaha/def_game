# 흡연자 벌목 기록 모드 — 숲 과밀 생존

> 다음 메타 진행 구현은 [벌목 기록 모드 메타 루프 v1](SCORE_ATTACK_META_LOOP.md)을 따른다. 런 종료 뒤 로비로 돌아가지 않고 `정산 → 기록전 영구 연구 → 다음 작업`으로 이어지며, 누적 정산 목재가 회사 등급과 기본 산림 압력을 자동으로 올린다.

## 플레이 규칙

- 로비의 `게임 시작` 아래 `벌목 기록 모드` 버튼 또는 `M` 키로 시작한다.
- 흡연자로 고정되며 활성 일반 나무 6그루에서 시작한다.
- 고정 제한 시간, 생산 버퍼, 초당 유지 요구량은 없다.
- 월드 전체의 **활성 일반 나무 수가 허용량에 닿는 즉시** 기록이 종료된다.
- 밑동, 장식 식물, 세계수, 재생 프리즘, 비활성 나무는 과밀도에 포함하지 않는다.

기본 허용량은 12그루다. 시작한 6그루도 과밀도와 총 산림 공급 기록에 포함한다. 시작 생성량은 기존 0.55그루/초에서 **0.16그루/초로 대폭 낮췄다.** 30초까지 0.16을 유지하고, 30~60초에는 0.16→0.28, 60~120초에는 0.28→0.55로 점진 상승한다. 아무것도 하지 않으면 남은 여섯 칸이 약 35~40초에 차므로 첫 작업도 바로 규칙을 이해할 수 있다.

## 몬스터 투입 곡선

기록 모드의 초반 주적은 몬스터가 아니라 숲 과밀이다. 첫 45초에는 몬스터가 나오지 않으며, 일반 스테이지의 숲 파괴율 25/50/75% 웨이브·정예·광폭화·덩굴 습격·재해도 기록 모드에서 실행하지 않는다. 시작 수목이 적어 파괴율 구간을 매우 빠르게 통과하더라도 기존 웨이브가 한꺼번에 쏟아지지 않게 구조적으로 차단한다.

45초 이후에는 동선을 조금 방해하는 동물 한 마리씩만 보충한다. 살아 있는 몬스터 상한과 보충 주기는 다음과 같다.

| 작업 시간 | 동시 몬스터 상한 | 보충 주기 |
|---:|---:|---:|
| 0~45초 | 0 | 없음 |
| 45~120초 | 1 | 32초 |
| 120~240초 | 2 | 26초 |
| 240~360초 | 3 | 22초 |
| 360초 이후 | 4 | 18초 |

한 번의 보충에는 한 마리만 나오며 상한에 도달한 동안 추가 스폰하지 않는다. 따라서 자동화가 갖춰지기 전에는 벌목과 구매 판단에 집중하고, 장기 기록부터 소수의 방해물을 처리하게 된다.

## 영구 성장

공용 특성 `벌목장 부지 확장`은 단계당 허용량을 4그루 늘린다. 최대 7단계에서 기본 12 + 특성 28 = 40그루가 된다. 허용량은 화면 안이 아니라 실제 플레이 월드 전체에 적용하므로 카메라 밖으로 나무를 밀어내는 방식으로 판정을 피할 수 없다.

| 특성 단계 | 허용량 |
|---:|---:|
| 0 | 12그루 |
| 1 | 16그루 |
| 3 | 24그루 |
| 5 | 32그루 |
| 7 | 40그루 |

## 영구 강화 재설계

기록 모드의 반복 수치 성장은 랜덤 카드에서 분리한다. 현재 로비 연구 화면은 기존 일반 작전 특성을 숨기고 기록전에 실제 적용되는 흡연자 연구 8종과 공용 나무 허용량만 표시한다. 숨긴 연구와 구매 기록은 삭제하지 않았으며 일반 작전 코드 복구 시 다시 사용할 수 있다.

| 영구 연구 | 단계당 효과 |
|---|---:|
| 출근 전 라이터 예열 | 최초 착화 준비시간 -0.12초 |
| 기록용 장초 필터 | 꽁초 사거리 +12 |
| 첫 설비 외상 장부 | 시작 목재 +3 |
| 산업용 점화 코일 | 착화 확률 +3%p |
| 대형 재받이 개조 | 착화 범위 +10 |
| 자동화 공동구매 | 자동화 구매 비용 -4% |
| 교대 없는 줄담배 | 투척 속도 +4% |
| 고온 불씨 압축 | 나무 피해 +0.5 |

`벌목장 부지 확장`은 별도 공용 연구로 단계당 활성 나무 허용량을 4그루 늘린다. 최초 착화 단축은 매 투척 재장전이 아니라 한 판의 첫 담배 준비에만 적용되고 최소 0.35초를 보장한다. 시작 목재는 결과의 벌목 획득량에 섞지 않으며 첫 자동화 구매를 앞당기는 초기 자본이다. 자동화 할인은 최대 20%다.

일반 스테이지의 카드와 분기 시스템은 그대로 유지한다. 기록 모드에서만 목재 경험치와 랜덤 3택을 끄고 영구 기초 성능 + 런 내 자동화 조달 구조를 사용한다.

## 목재 자동화 조달

벌목으로 얻은 목재는 즉시 쓸 수 있는 런 전용 잔액이 된다. 화면 우측 하단의 전용 픽셀 아이콘을 클릭하거나 `Z/X/C/V`로 구매한다.

| 키 | 자동화 | 역할 | 1단계 비용 |
|---|---|---|---:|
| Z | 자동 꽁초 투척기 | 주변의 타지 않은 나무를 자동 추적·투척 | 12 |
| X | 건초 공급기 | 건초 설치 주기와 화염 지대 강화 | 18 |
| C | 폐유 회수 펌프 | 불탄 나무의 폭발과 연쇄 강화 | 24 |
| V | 산림 증설 계약 | 공급량과 나무 체력 동시 증가 | 30 |

각 설비는 6단계이며 비용은 단계마다 증가한다. 산림 증설 계약은 허용량을 올리지 않으므로 더 많은 재료와 더 단단한 나무를 동시에 받아들이는 고위험 투자다. 결과 화면은 총 획득 목재와 자동화 투자액을 따로 기록한다.

## 산림 공급과 빌드 폭주

생성률은 기본 시간 압력과 최근 1초 벌목량을 함께 본다. 단, 실제 벌목량 추종은 30초 전에는 꺼져 있고 30~90초 사이에 서서히 연결된다. 한두 그루를 처음 벤 순간 생성량이 갑자기 폭증하지 않으며, 빌드가 갖춰진 뒤에는 최근 생산력의 108%까지 공급을 따라 올린다. 따라서 초반에는 조작과 첫 자동화를 고를 시간이 있고, 완성된 빌드는 충분한 재료를 공급받으면서도 조금씩 쌓이는 숲을 계속 밀어내야 한다.

자동화 `산림 증설 계약`은 레벨마다 공급량과 나무 체력을 함께 25% 올린다. 더 많은 나무를 얻는 대신 한 그루를 처리하는 비용도 커지는 위험 선택이며 허용량은 늘리지 않는다. 이미 자란 나무도 현재 피해 비율을 보존한 채 강화된 최대 체력으로 환산한다.

## 표시와 결과

HUD 중앙은 `숲 과밀도 현재 / 허용량`을 표시한다.

- 70% 미만: 안정
- 70% 이상: 황색 경고
- 85% 이상: 적색 위험
- 100%: 즉시 종료

좌측에는 누적 작업 시간, 현재 1초 생산력, 현재 자동 생성률이 표시된다. 결과 화면에는 버틴 시간, 총 벌목, 최고 생산력, 나무 허용량, 최고 활성 나무 수, 총 산림 공급량을 기록한다. 등급은 30초 C, 1분 B, 3분 A, 6분 S를 기준으로 한다.

기술적 무한 실행만 막기 위해 12분 숨은 하드캡을 유지한다. 일반 플레이 판정과 UI에는 제한 시간으로 노출하지 않는다.
