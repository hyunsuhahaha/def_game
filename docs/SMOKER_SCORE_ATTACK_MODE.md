# 흡연자 벌목 기록 모드

## 진입과 종료 조건

- 로비의 `게임 시작` 아래 `벌목 기록 모드` 버튼 또는 `M` 키로 시작한다.
- 흡연자 전용이며 수확 가능한 나무 0그루인 빈 땅에서 출발한다.
- 고정 기본 시간과 별도 조립 구간은 없다. 시작 순간부터 실제 벌목 생산량으로 10초 생산 버퍼를 유지한다.
- 세계수와 재생 토템은 등장하지 않는다.

## 생산 유지 곡선

최근 1초 동안 실제로 쓰러뜨린 나무 수를 현재 생산력으로 사용한다.

| 작업 시간 | 유지 필요 벌목량 |
|---|---:|
| 0~30초 | 1그루/초 |
| 30~60초 | 2그루/초 |
| 60~90초 | 4그루/초 |
| 90~120초 | 8그루/초 |
| 120~150초 | 16그루/초 |
| 150초 이후 | 32그루/초부터 30초마다 2배 |

버퍼 변화량은 `현재 생산력 / 유지 필요량 - 1` 초/초다. 3/2이면 초당 0.5초씩 회복하고 6/8이면 초당 0.25초씩 감소한다. 버퍼는 10초를 넘지 않으며 0이 되는 즉시 기록이 종료된다.

레벨업 카드와 스킬 분기는 런 내내 유지한다. 고정 조립 시간이 없으므로 생산을 유지하면서 빌드를 완성해야 한다.

## 산림 자동 공급

공급 부족이 패배 원인이 되지 않도록 나무 생성률은 `기본 생성률`, `현재 생산력 × 1.25`, `유지 필요량 × 1.15` 중 가장 높은 값으로 자동 증설한다. 요구 단계가 오르면 나무 간격과 활성 나무 상한도 동적으로 조절한다. 기술적 안전장치로 총 작업 시간 12분에 숨은 하드캡을 둔다.

레벨업 카드 `산림 증설`은 레벨마다 자동 공급 결과와 새 나무 체력을 함께 25% 올린다. 즉 재생량을 두 배 가까이 키우면 개별 나무도 두 배 가까이 단단해진다. 카드를 고르는 순간 이미 자란 나무도 현재 체력 비율을 유지한 채 새 최대 체력으로 환산한다. 시스템이 요구량 부족을 막기 위해 자동으로 올리는 기본 공급분 자체는 체력 배율로 다시 계산하지 않아 난이도가 이중으로 폭증하지 않는다.

## HUD와 결과

HUD는 종료 시각 대신 누적 작업 시간, 생산 버퍼, 현재 생산력, 유지 필요량을 표시한다.

결과 화면 기록:

- 총 작업 시간
- 생산 유지 시간
- 총 벌목량
- 최고 생산력
- 최대 유지 단계
- 총 산림 공급과 최고 활성 나무

기록 등급은 생산 유지 시간 30/60/120/180초 경계를 사용한다.
