# 흡연자 10분 벌목 기록 모드

## 진입

- 로비의 `게임 시작` 아래 `벌목 기록 모드` 버튼 또는 `M` 키로 바로 시작한다.
- 기존 스테이지·지구본·캐릭터 선택 흐름과 분리된 흡연자 전용 모드다.
- 일반 벌목 작전은 변경하지 않는다.

## 현재 규칙

- 제한 시간은 정확히 10분이다.
- 시작 시 수확 가능한 나무는 0그루다. 바닥 장식과 지형은 유지하지만 기존 숲 목표와 재생 토템은 생성하지 않는다.
- 기본 나무 생성률은 초당 `0.55그루`이며 `treeSpawnRate × scoreSpawnRateMultiplier`로 계산한다. 이후 빌드 선택이 이 배율을 올릴 수 있도록 별도 필드로 분리했다.
- 새 나무는 플레이 가능 지형과 수관 안전 여백 안에서만 생성되며 기존 나무·주요 배경 소품과 겹치지 않는다.
- 나무는 `score_growth` 등장 애니메이션으로 자라난 뒤에 정상적인 체력·화재·벌목 판정을 사용한다.
- 활성 나무는 최대 180그루다. 쓰러진 노드 슬롯을 재사용하므로 10분 동안 런타임 객체 수가 무한히 늘어나지 않는다.
- 숲이 잠시 0그루가 되어도 세계수는 등장하지 않는다. 생성 타이머는 계속 진행된다.

## HUD와 결과

- HUD는 남은 시간, 목재, 총 벌목, 총 생성, 현재 활성 나무, 초당 생성률을 표시한다.
- 중앙 숲 게이지는 기존 파괴율 대신 현재 활성 나무 수를 표시한다.
- 시간 종료 결과에는 총 벌목, 생성된 나무, 총 목재, 최고 활성 나무, 최종 생성률을 기록한다.
- 결과 화면의 재도전은 다시 빈 땅에서 같은 기록 모드를 시작한다.
