# 흡연자 벌목 기록 모드 — 영구 재생 단계

> 현재 활성 개발 모드는 흡연자 전용 `score_attack`이다. 다른 작전과 작업자 코드는 삭제하지 않고 로비 진입만 비활성화한다.

## 핵심 진행

- 활성 일반 나무 6그루에서 시작한다.
- 저장 파일의 `regenTier`가 이번 런의 시작 재생 단계다. 2단계를 해금했다면 다음 판도 2단계에서 시작한다.
- 활성 일반 나무가 0그루인 상태가 0.3초 유지되면 재생 단계가 1 상승하고 즉시 저장된다. 이어지는 0.86초에는 전투를 멈추고 잎 입자 집결 → 단계 숫자 점화 → 잎/빛 파편 확산을 보여 준다. 0.38초 충격 박자부터 다음 숲 6그루가 0.065초 간격으로 순차 발아한다.
- 단계 상승은 카드를 지급하지 않는다. 새 단계의 나무 6그루가 성장 연출과 함께 다시 공급된다.
- 고정 제한 시간은 없다. 활성 일반 나무가 허용량에 닿으면 종료한다.
- 밑동, 장식 식물, 세계수, 재생 프리즘, 비활성 나무는 과밀도에서 제외한다.

기본 재생 속도는 영구 재생 단계의 기초 공급량 위에 실제 플레이 시간 압력을 곱한다. 추가로 활성 나무가 허용량의 60% 이상이고 최근 5초 벌목량이 자연 재생보다 낮은 상태가 5초 지속되면 내부 재생 가속이 시작된다. 가속 직후 재생은 최소 초당 1.35그루가 되고 계속 밀리면 더 빨라져, 회복 가능성이 없는 런을 오래 끌지 않는다. 이 상태를 알리는 별도 문구는 HUD에 표시하지 않는다.

```text
초당 재생 = 0.14 × 1.75^(재생 단계 - 1) × 2^(플레이 시간 / 60초)
나무 HP 배율 = 1.03^(재생 단계 - 1)
```

| 단계 | 초당 재생 | HP 배율 |
|---:|---:|---:|
| 1 | 0.14 | 1.00 |
| 2 | 0.25 | 1.03 |
| 3 | 0.43 | 1.06 |
| 4 | 0.75 | 1.09 |
| 5 | 1.31 | 1.13 |
| 6 | 2.30 | 1.16 |
| 8 | 7.04 | 1.23 |
| 10 | 21.55 | 1.30 |

HP 계산은 정수 반올림을 사용한다. 따라서 낮은 단계에서는 기본 체력이 그대로 유지되고, 몇 단계를 통과할 때마다 1씩 완만하게 오른다. 반면 6단계의 공급량은 1단계의 약 16.4배이므로 실제 난도는 화면을 다시 채우는 나무 수가 주도한다.

| 플레이 시간 | 시간 압력 |
|---:|---:|
| 시작 | ×1 |
| 1분 | ×2 |
| 2분 | ×4 |
| 3분 | ×8 |
| 4분 | ×16 |
| 6분 | ×64 |

시간 압력은 연속적으로 증가한다. 재생 단계를 올리지 않고 현재 벌목량과 공급량만 맞춰도 요구 공급량이 계속 앞서가므로 이론상 무한 플레이가 불가능하다. 카드 선택과 재생 단계 상승처럼 전투가 정지된 동안에는 플레이 시간이 증가하지 않는다.

## 목재 경험치와 운영·전투 카드

직접 획득하거나 아기 로봇이 회수한 목재는 목재 경험치가 된다. 첫 강화 요구량은 5이며 이후 8, 11, 14처럼 3씩 증가한다. 아기 로봇은 플레이어를 따라다니지 않고 맵 전체의 착지한 목재를 항상 탐지해 그 자리로 이동하며, 목재가 없으면 현재 위치에서 대기한다. 여러 로봇은 같은 목재에 몰리지 않고 서로 다른 목표를 나눠 맡는다. 경험치 요구량을 채울 때마다 게임을 멈추고 운영·전투 카드 3개 중 하나를 고른다. 여러 레벨이 한꺼번에 올랐다면 남은 선택을 순서대로 처리한다.

기록 모드 드래프트에는 다음 열 장만 등장한다. 이름은 효과를 그대로 사용한다.

| 운영 카드 | 런 중 효과 |
|---|---|
| 아기 운반 로봇 | 떨어진 목재를 즉시 경험치로 회수하고 강화 시 수와 기동력이 증가 |
| 목재 탐지 안테나 | 맵 전체 탐지는 기본 적용, 이동속도 단계당 18% 증가 |
| 작업장 확장 | 이번 런의 나무 허용량 단계당 +1 |
| 조림 구획 지정 | 가장자리 생성을 줄이고 작업자 주변 생성 비중 증가 |
| 목재 선별기 | 목재 경험치 단계당 +15% |
| 안전 관리 장치 | 과밀 종료 유예시간 단계당 +0.25초 |
| 공격속도 상승 | 흡연·투척 동작속도 단계당 +18% |
| 추가 꽁초 투척 | 클릭당 추가 꽁초 단계당 +1 |
| 착화 범위 상승 | 착화 범위 단계당 +24 |
| 연소속도 상승 | 나무 연소속도 단계당 +18% |

모든 운영 카드는 최대 3레벨이며 다음 런에는 초기화된다. 리롤, 배니시, 아르카나, 융합은 이 운영 드래프트에서 의도적으로 비활성화한다. 일반 작전의 기존 카드·융합·시너지 코드는 삭제하지 않는다.

## 영구 전투 특성

로비에서는 인게임 스킬 레벨을 미리 사지 않는다. 성과 포인트로 흡연자의 동작을 작은 특성으로 나눠 구매한다.

| 갈래 | 개별 특성 |
|---|---|
| 투척 | 사거리, 꽁초 비행 속도 |
| 착화 | 불씨 전이 반경, 꽁초 착화 확률 |
| 확산 | 불붙은 나무의 주변 확산 확률, 연소 속도 |
| 조작 | 최초 흡연 준비시간, 흡연·재장전 속도 |
| 최종 | 투척 시 추가 꽁초 1개 |

기존 `fire_score_filter/lighter/ash/drag/heat` 저장 키는 새 세부 특성에 그대로 대응시켜 이미 구매한 레벨과 사용한 성과 포인트를 잃지 않는다. 새 착화 확률·비행 속도·추가 꽁초 노드는 0레벨부터 시작한다. `molotov`, `dry_forest`, `straw_bale`, `smoke_ring`, `oil_drum` 레벨은 영구 특성이 직접 지급하지 않는다.

### 꽁초 착화 피드백

꽁초의 바닥 잔류와 확률 확산 규칙은 그대로 유지한다. 착지 순간에는 10프레임 전용 픽셀 아틀라스로 백열점·불티·재 파편을 보여 주고, 불씨가 나무에 도착하면 별도의 10프레임 밑동 착화 아틀라스와 짧은 나무 흔들림을 재생한다. 착지와 착화는 서로 다른 짧은 효과음을 사용한다. 이 반응은 카메라 트라우마를 추가하지 않아 2.5D 화면 전체를 흔들지 않는다.

공용 `벌목장 부지 확장`, 아기 로봇 기본 지급과 고속 모터도 기존대로 적용한다. `두더지 작업반 채용` 1단계를 해금하면 기존 고밀도 두더지 스프라이트의 작은 동료가 런 시작부터 맵 전체의 가장 가까운 활성 나무를 찾아 이동하고 전용 손톱 접촉 프레임에 2피해를 주어 혼자 벌목한다. 2~6단계는 단계마다 피해 +1, 이동속도 +8%, 공격속도 +10%를 더하며 3/5단계에는 손톱 자국 티어가 커지고 6단계에는 하나의 양손 할퀴기 이펙트가 재생된다. 나무가 쓰러지거나 발아 중이면 즉시 다른 완성된 나무를 다시 찾으며 플레이어를 따라다니지 않는다. 이전 일반 작전 특성과 구매 기록은 저장 파일에 보존한다.

## 표시와 결과

- HUD: 현재 재생 단계, 초당 생성량, 활성 나무/허용량
- 결과: 시작 단계, 이번 런 최고 단계, 운영 레벨, 최종 생성 속도, 총 공급과 벌목량
- 성과 포인트: 시작 단계 기본 보상 + 제한된 벌목 보상 + 이번 런 신규 단계당 보너스
- 12분 숨은 하드캡은 기술적 무한 실행만 막으며 제한 시간으로 노출하지 않는다.
