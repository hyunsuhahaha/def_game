# 흡연자 벌목 기록 모드 — 숲 과밀 생존

> 현재 활성 개발 모드는 흡연자 전용 `score_attack`이다. 다른 작전과 작업자 코드는 삭제하지 않고 로비 진입만 비활성화한다.

## 플레이 규칙

- 활성 일반 나무 6그루에서 시작한다.
- 고정 제한 시간은 없고, 월드 전체의 활성 일반 나무가 허용량에 닿는 즉시 종료한다.
- 밑동, 장식 식물, 세계수, 재생 프리즘, 비활성 나무는 과밀도에서 제외한다.
- 기본 허용량은 12그루다. `벌목장 부지 확장`은 단계당 4그루, 최대 28그루를 추가한다.
- 시작 산림 공급은 0.16그루/초다. 30초까지 유지한 뒤 30~60초에 0.28, 60~120초에 0.55까지 오른다.
- 최근 벌목량 추종은 30초 뒤부터 서서히 연결돼 후반 빌드에 재료가 부족하지 않게 한다.

## 목재 경험치와 레벨업

나무에서 얻은 목재는 즉시 경험치에 합산된다. 경험치 요구량을 채울 때마다 게임을 잠시 멈추고 현재 **흡연자 전용 스킬만으로 서로 다른 카드 3개**를 제시한다. 하나를 선택하면 다음 레벨로 진행하며, 여러 레벨이 한꺼번에 올랐다면 남은 선택을 순서대로 처리한다.

현재 드래프트는 꽁초 투척, 건조주의보 무시, 라이터 기름 유출, 마른 건초더미 생성, 도넛 강화 5종과 공용 유틸리티인 아기 운반 로봇으로 한정한다. 공용 전투 스킬 7종의 코드·자산·연습장 목록은 삭제하지 않고 보존하지만 레벨업 카드에는 나오지 않는다. 아기 로봇은 바닥에 떨어진 목재만 찾아 플레이어에게 배달하며 Lv.1/3/5에 1/2/3대로 늘고 레벨마다 탐색 범위와 이동속도가 증가한다. 3레벨 분기와 6레벨 진화 규칙은 유지한다. 기록 모드 전용 자동화 구매 바, `Z/X/C/V` 단축키, 자동 꽁초·건초·폐유·산림 증설 계약은 제거했다.

## 몬스터 투입

첫 45초에는 몬스터가 나오지 않는다. 일반 작전의 파괴율 웨이브, 정예, 광폭화, 덩굴 습격, 재해도 실행하지 않는다.

| 작업 시간 | 동시 몬스터 상한 | 보충 주기 |
|---:|---:|---:|
| 0~45초 | 0 | 없음 |
| 45~120초 | 1 | 32초 |
| 120~240초 | 2 | 26초 |
| 240~360초 | 3 | 22초 |
| 360초 이후 | 4 | 18초 |

## 영구 연구

활성 연구 화면은 기록전에 실제 적용되는 흡연자 연구 6종과 공용 나무 허용량 연구만 표시한다.

| 영구 연구 | 단계당 효과 |
|---|---:|
| 출근 전 라이터 예열 | 최초 착화 준비시간 -0.12초 |
| 기록용 장초 필터 | 꽁초 사거리 +12 |
| 산업용 점화 코일 | 착화 확률 +3%p |
| 대형 재받이 개조 | 착화 범위 +10 |
| 교대 없는 줄담배 | 투척 속도 +4% |
| 고온 불씨 압축 | 나무 피해 +0.5 |
| 벌목장 부지 확장 | 활성 나무 허용량 +4 |

최초 착화 단축은 한 판의 첫 담배 준비에만 적용하고 최소 0.35초를 보장한다. 이전 모드의 특성과 구매 기록은 저장 호환을 위해 보존하지만 현재 기록전 계산에는 합산하지 않는다.

## 표시와 결과

HUD 중앙은 현재 활성 나무와 허용량을 표시한다. 70%부터 황색, 85%부터 적색으로 경고하며 100%에서 즉시 종료한다. 결과 화면에는 버틴 시간, 총 벌목, 최고 생산력, 도달 레벨, 나무 허용량, 최고 활성 나무 수, 총 산림 공급량을 기록한다. 12분 숨은 하드캡은 기술적 무한 실행만 막으며 제한 시간으로 노출하지 않는다.
