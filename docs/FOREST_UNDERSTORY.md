# 온대 숲 거목·하층식생 규격

## 화면 기준

검수 화면은 [`previews/forest-tall-understory-v1.png`](previews/forest-tall-understory-v1.png)다. 온대 숲과 초심자의 숲에 적용한다.

- 거목은 90년대 애니메이션 배경 같은 성숙한 숲의 정서를 사용한다. 굵고 곧은 줄기가 화면 세로축을 만들고, 수관은 높은 곳에서 불규칙하게 갈라진다.
- 둥근 잎송이를 포도·브로콜리처럼 반복하거나 귀여운 얼굴, 과장된 장식, 실사 질감을 넣지 않는다.
- 거목은 기존 목표 나무 약 17그루 중 한 그루를 시각적으로 교체한다. 체력·보상·충돌·재생·목표 개수는 일반 활엽수와 같다.
- 거목은 1.82초 동안 초반 버팀, 목재 마찰음, 중간 가속을 거쳐 쓰러진다. 착지할 때 쓰러진 선을 따라 낮은 흙먼지와 잎이 퍼지고 마지막 충돌에만 큰 카메라 진동을 준다.
- 바닥은 짧은 잔디·클로버·흙결이 있는 지면층, 낮은 지피식물층, 걷기에 반응하는 큰 풀 포기층으로 나눈다.

## 반응형 풀

`assets/scenery/forest/grass-understory-atlas-pixel-v1.png`은 같은 풀 포기의 네 상태를 128×96 셀로 가진다.

1. 정지
2. 왼쪽으로 눕기
3. 오른쪽으로 눕기
4. 영구 절단 밑동

플레이어가 포기의 타원형 발밑 영역을 지나면 이동 방향으로 0.34초간 눕고 짧은 바스락 소리를 낸다. 나무 타격이나 범위 공격이 닿으면 한 번에 잘리며, 해당 스테이지 동안 절대 다시 자라지 않는다. 풀은 나무 수·목재·성과·재생 구역·공격 자동 조준에 포함하지 않는다.

## 자산 수치

- 거목 원본: `256×620`, 하드 알파, 112색 계단 명암, nearest 필터
- 풀 아틀라스: `512×96`, 4프레임, 하드 알파, 56색 공용 팔레트, nearest 필터
- 거목 월드 배율: 일반 나무와 같은 `1.0` 변형 배율
- 풀 월드 폭: 약 `85–118`, 배치별 축소·반전·톤 차이를 허용

## 완료 검사

- 실제 게임 카메라에서 거목의 뿌리와 높은 수관이 동시에 읽힌다.
- 풀 포기가 철사나 단색 삼각형으로 보이지 않고 넓은 잎과 어두운 밑동을 가진다.
- 걷기 방향 두 상태와 절단 상태가 정지 상태와 동일한 뿌리 좌표를 쓴다.
- 거목과 풀 때문에 목표 수, 자동 조준, 이동 충돌, 재생 로직이 변하지 않는다.
- 자동 캡처는 보이지 않는 LÖVE 창으로 수행하고 실제 결과를 눈으로 확인한다.
