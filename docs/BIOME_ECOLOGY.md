# 지역 생태 조사와 적 구성

**2026-08-26 사용자 요청: 이름만 다른 맵이 아니라 누구나 장소를 알아볼 수 있어야 한다. 맹그로브에는 악어, 마다가스카르에는 화난 원숭이 같은 지역별 적을 넣는다.**

## 현재 구현과 제안의 경계

- 구현: 온대 숲/맹그로브/마다가스카르/무인도 선택, 새 지역별 나무 3종, 환경용 게·여우원숭이·앵무새·부채잎 식물. 환경 생물은 적/전리품/벌목 목표가 아니다.
- 전투 구현: 맹그로브는 늪지 게와 바다악어, 마다가스카르는 화난 알락꼬리여우원숭이, 무인도는 해변 게가 일반/시간/정예 스폰에 등장한다. 악어는 물길에서 생성되어 접근 → 방향 고정 예고 → 돌진 → 회복, 여우원숭이는 더 짧은 예고 뒤 도약한다. 게는 기존 근접 추격/접촉 공격을 사용한다. 새 맵의 일반 포탑은 기존 덩굴 새싹으로 바뀌며 보스·사신은 공통으로 유지한다.
- **아래 표는 확장 후보까지 포함한다. 물왕도마뱀·망둑어·물총새·시파카·포사, 악어의 잠복 눈/V자 물결 및 게의 전용 집게 패턴은 미구현이다. 모든 제안이 완성된 것으로 설명하지 않는다.**
- 실제 서식·외형을 참고하되 공격성, 투사체, 보스 거대화는 게임 각색이다. 현실의 동물이 사람에게 이런 패턴으로 공격한다고 설명하지 않는다.

## 1. 맹그로브: 인도태평양 하구·기수 습지

근거: 싱가포르 NParks는 바다악어의 하구·맹그로브 서식과 물가/식생에 숨는 행동을 기록한다. 물왕도마뱀도 맹그로브와 수로에서 발견된다. 망둑어·게·물총새를 함께 쓰면 물길을 단순 파란 길로 보이지 않게 만들 수 있다.

| 실제 생물/특징 | 게임용 역할 제안 | 등장 위치·예고 |
|---|---|---|
| 바다악어: 넓은 주둥이, 낮은 긴 몸, 강한 꼬리 | 대표 중형 적. 잠복 → 방향 고정 예고 → 짧은 돌진/물기 → 회복 | 물길 또는 진흙 둑에서 등장. 수면의 눈과 V자 물결을 먼저 표시 |
| 물왕도마뱀: 긴 목과 꼬리, 수륙 이동 | 측면으로 접근해 꼬리 휘두르기 | 뿌리 주변/물가. 꼬리를 말아 올리는 준비동작 |
| 농게: 한쪽의 큰 집게 | 느린 갑각 탱커 또는 소형 군집 적 | 진흙 둑. 큰 집게를 들어 범위 예고 |
| 망둑어: 물과 갯벌 사이를 이동하는 물고기 | 작은 도약형 적 또는 환경 생물 | 젖은 진흙. 바닥 착지점 예고 |
| 흰목물총새: 맹그로브에 사는 새 | 물가 횃대·짧은 비행 환경 연출 | 수면/낮은 가지 |

출처: [NParks 바다악어](https://www.nparks.gov.sg/florafaunaweb/fauna/2/5/259), [물왕도마뱀](https://biodiversitysg.nparks.gov.sg/our-biodiversity/reptiles/lizards/malayan-water-monitor/), [농게](https://www.nparks.gov.sg/florafaunaweb/fauna/4/0/400), [습지 생물 안내](https://www.nparks.gov.sg/-/media/nparks-real-content/learning/learning-journeys/guided-walks/diy-guided-walks/sungei-buloh/diy-trail-guide.pdf), [물총새](https://www.nparks.gov.sg/florafaunaweb/fauna/3/4/34).

**아트 제한:** 단순 녹색 멧돼지나 몸이 짧은 공룡을 악어라고 부르지 않는다. 땅에 붙은 긴 몸·턱·꼬리가 실루엣에서 읽혀야 한다. 붉은 마코앵무는 이 지역의 대표 조류로 재사용하지 않는다.

## 2. 마다가스카르: 서부·남서부 건조림을 중심으로

바오밥과 붉은 땅을 핵심으로 잡았으므로 우림의 모든 종을 무작정 섞지 않는다. Kew는 Grandidier 바오밥의 원산 범위를 서부 마다가스카르, 주요 생육 환경을 건조 관목지/사막 생물군계로 기록한다. Duke Lemur Center는 알락꼬리여우원숭이를 남서부 건조림과 연결한다. 이는 넓은 지역 콘셉트를 뒷받침하며 **특정 바오밥 군락과 특정 동물의 정확한 공존을 입증하는 자료는 아니다.**

| 실제 생물/특징 | 게임용 역할 제안 | 외형·행동의 식별점 |
|---|---|---|
| 알락꼬리여우원숭이: 흑백 띠 꼬리, 무리 생활, 지상 활동 | 사용자 요청의 **화난 원숭이 역할**. 무리로 접근해 짧은 도약 공격 | 일반 원숭이 꼬리 금지. 꼬리를 세우고 웅크리는 준비동작 |
| 시파카: 특징적인 지상 도약 | 측면으로 튀며 접근하는 회피형 적 | 긴 팔다리·옆으로 뛰는 실루엣. 정확한 종/분포는 자산 제작 전 추가 확인 |
| 포사: 긴 꼬리, 민첩한 토착 포식자 | 정예 추격자. 우회 → 짧은 돌진 | 긴 몸과 꼬리, 둥근 귀. 사자나 표범 무늬로 대체하지 않음 |
| 바오밥 | 주요 벌목 대상/지역 보스 모델 후보 | 가지 없는 굵은 통형 줄기, 꼭대기의 짧은 가지와 낮은 수관 |
| 여행자나무(Ravenala): 부채 형태 잎 | 제한적인 식생 포인트 | 실제로 마다가스카르 원산이지만 건조 바오밥 숲 전체를 부채잎으로 덮지 않음 |

출처: [Kew 바오밥](https://powo.science.kew.org/taxon/558630-1), [Duke 알락꼬리여우원숭이](https://lemur.duke.edu/discover/meet-the-lemurs/ring-tailed-lemur/), [Duke 지상 활동·무리](https://lemur.duke.edu/accordions/fat-tailed-dwarf-lemur-husbandry-guidelines-2/), [Duke 시파카](https://lemur.duke.edu/taxonomy/), [San Diego Zoo 포사](https://animals.sandiegozoo.org/animals/fossa), [NParks 여행자나무](https://www.nparks.gov.sg/florafaunaweb/flora/3/1/3100).

여우원숭이는 원숭이와 같은 동물이 아니라 별도의 영장류 계통이다. 사용자 의도인 “화난 원숭이처럼 활발한 적”은 유지하면서 지역을 나타내는 여우원숭이 외형을 쓴다. [Smithsonian 설명](https://www.smithsonianmag.com/blogs/national-zoo-conservation-biology-institute/2021/11/03/stink-fights-and-two-tongues-5-surprising-facts-about-lemurs/)

## 3. 무인도: 해변·내륙·공중의 역할 구분

열대 섬은 하나의 생태계가 아니다. 실제 지리 모델을 정하지 않은 현재 맵은 **가상의 열대 섬**이다. 미 어류야생동물관리국의 팔미라 환초 자료는 열대 섬의 숲·바닷새·육지게·산호초 조합을 참고하기 좋지만, 그곳에 마코앵무가 산다는 근거로 사용하지 않는다.

| 공간 | 후보/역할 | 주의 |
|---|---|---|
| 백사장 | 육지게·소라게 군집, 발자국·굴·떠밀린 나무 | 농게·소라게·야자집게를 같은 스프라이트의 이름만 바꿔 쓰지 않기 |
| 야자수 안쪽 | 앵무새 환경 연출, 열매/둥지 포인트 | 마코류는 중남미 계열. 인도태평양 섬으로 확정하면 지역 앵무새로 다시 선정 |
| 해안 공중 | 제비갈매기 등 바닷새, 경고 후 강하하는 비행 적 후보 | 정확한 종은 기준 섬을 정한 뒤 확정 |
| 해변 정예/보스 | 거대 육지게. 옆걸음 → 집게 예고 → 내려찍기 | 거대화와 공격은 창작. 야자집게를 채택할 경우 인도태평양 분포에 맞출 것 |

출처: [USFWS 팔미라 환초](https://www.fws.gov/refuge/palmyra-atoll), [UT Austin 야자집게](https://utmsi.utexas.edu/science-and-the-sea/radio-program/coconut-crabs/), [San Diego Zoo 마코앵무](https://animals.sandiegozoo.org/animals/macaw).

현재 앵무새는 마코형 색·부리의 **가상 섬 연출 자산**이며, 팔미라나 다른 특정 섬의 고증 재현으로 표시하면 안 된다.

## 4. 다음 전투 구현 순서

1. 맹그로브 바다악어: 물가 생성 → 잠복 예고 → 돌진/물기. 무작위 위치에서 갑자기 접촉 피해를 주지 않는다.
2. 마다가스카르 화난 알락꼬리여우원숭이: 무리 생성 → 도약 준비 → 공격 → 회복. 기본 숲의 다람쥐를 단순 재색칠하지 않는다.
3. 지역별 느림/빠름/원거리 역할을 채우는 보조 적 2종씩. 기존 보스 유지 여부도 별도로 결정한다.
4. 무인도는 기준 지역을 먼저 좁힌 뒤 게와 비행 적을 제작한다. 맵마다 동일 멧돼지/다람쥐 출현이 계속되면 지역 작업 완료로 보지 않는다.

## 5. 모든 후속 AI의 검수 기준

- 이름과 UI를 가려도 지형, 대표 실루엣, 생물 중 최소 두 가지로 지역을 구분할 수 있어야 한다.
- 최소 대표 적 1종은 외형뿐 아니라 진입 위치·공격 패턴도 지역 지형과 연결한다.
- 생물은 모래/진흙/수면/수관 등 맞는 구역에 배치한다. 숲 바닥 전체에 동일한 소품을 균일 살포하지 않는다.
- [그래픽 스타일 가이드](GRAPHICS_STYLE_GUIDE.md)는 여전히 우선한다. 생태 조사가 실사풍 전환의 근거가 되지 않는다.
- 위 출처의 생태 사실과 게임 기획을 구분한다. 미제작 후보를 구현 완료 목록에 올리지 않는다.
