# 코인 채굴꾼 — 손톱 강화

`detector`는 코인 채굴꾼 전용 6단계 기본 공격 강화다. 피해·사거리·폭뿐 아니라 실제 표시되는 할퀴기 궤적도 함께 성장한다.

- 두더지 몸에서는 아무 이펙트도 뻗어나오지 않는다.
- 마우스로 지정한 공격 지점 또는 실제 맞은 나무·적 표면에서만 5프레임 할퀴기가 발생한다.
- 모든 단계: 공격 지점에서 입력 방향으로 휘어 나가는 가는 발톱 호 4개
- 판정의 반폭을 렌더러에 직접 전달한다. 아틀라스 중심에서 발톱 끝까지의 39px를 이 값에 맞춰 확대하므로 실제 피격 폭과 보이는 발톱 폭이 항상 같다.
- 6레벨: 좌우 두 손의 발톱 궤적을 서로 반대 곡률로 동시에 표시한다. 두 궤적의 오프셋과 각 궤적 폭의 합은 단일 판정 반폭과 정확히 같으며 피해는 한 번만 적용된다.
- 준비 동작 중 두더지가 이동해도 입력 당시의 방향 벡터를 현재 위치에 다시 적용한다. 접촉 프레임이 과거 마우스 월드 좌표를 향해 빗나가지 않는다.
- 나무는 밑동 한 점이 아니라 `node.y-150`부터 밑동까지의 세로 실루엣으로 판정한다. 발톱 이펙트도 계산된 실제 접촉 높이에 생성한다.
- 아틀라스가 기준점보다 앞으로 뻗는 `85/39 × 판정 반폭`만큼 실제 사거리도 연장한다. 보이는 발톱 끝에 닿았는데 피해가 없는 구간을 만들지 않는다.
- 같은 궤적 안의 나무와 몬스터는 앞의 한 대상만 고르는 제한 없이 모두 한 번씩 맞는다.
- 1–2단계: 짧고 가는 흰색 호와 어두운 잔흔
- 3–4단계: 조금 더 긴 흰색 호와 작은 표면 파편
- 5–6단계: 가장 길고 밝은 흰색 호와 추가 끝 파편(선 굵기는 유지)
- 접촉 애니메이션은 0.22초, 완성된 손톱자국은 같은 월드 좌표에 6초간 남는다.
- 모든 단계가 흙·나무 표면색의 홈과 밝은 찢김 테두리를 사용하며 에너지 빔이나 색깔 레이저로 변하지 않는다.
- 아틀라스는 오른쪽(+X) 진행을 기준으로 제작하고 런타임에서는 추가 각도 오프셋 없이 `두더지 → 공격 지점` 벡터로 회전한다. 따라서 상·하·좌·우·대각선 모두 입력 방향과 일치한다.
- 왼쪽 공격의 곡률을 기준 형태로 유지한다. 오른쪽 공격은 단순 180도 회전이 아니라 로컬 Y축을 반전한 정확한 거울상을 사용해 네 발톱 호의 휘어짐과 진행 방향이 좌우 대칭이 된다.

런타임 아틀라스는 `assets/fx/mole-claw/mole-claw-swipe-cartoon-pixel-v1.png`, 렌더러는 `src/mole_claw_art.lua`다. 걷기 원본은 왼쪽을 향하지만 공격 원본 2–3프레임은 오른쪽을 향하므로 `nativeFacing=-1`과 `actionFacing={1,-1,-1,...}`을 함께 사용해 두 행을 독립적으로 정규화한다. 공격 1–3프레임은 발 기준점을 고정한 프레임별 보정 배율을 사용해 공격 순간 몸이 작아 보이지 않게 한다.
