# 벌목 작전 HUD·결과 UI v5 — 결과와 연구의 단일 시선 흐름

HUD를 시계·나무판·표찰 같은 소품으로 디자인하지 않는다. 같은 테두리의 카드 반복도 쓰지 않는다. 플레이 화면과 수목을 가리지 않는 **텍스트, 픽셀 바, 짧은 구분선**만 사용한다.

## HUD

- 시간·구역·직업·목재·벌목량은 배경 없는 짧은 텍스트다.
- HP는 14px 높이의 빨간 막대 하나다. 단색 채우기 대신 위쪽 밝은 하이라이트부터 아래쪽 암부까지 하드 에지 4단 명암을 직접 찍는다.
- 남은 숲은 같은 구조의 초록 막대 하나다.
- 6개 구역은 숫자와 3px 상태선만 표시한다.
- 콤보는 패널, 아이콘, 타이머 바 없이 큰 숫자와 `COMBO`만 표시한다.
- 보스와 재난처럼 즉시 대응해야 하는 정보 외에는 별도 프레임을 추가하지 않는다.

## 결과 화면

- 나무판, 종이, 도구 소품, 통계 카드 격자를 사용하지 않는다.
- 기존 월드 배경을 남긴 어두운 오버레이 위에 `종료 원인 → 생존 기록 → 핵심 수치 3개 → 성과 포인트` 순서로 둔다.
- 세부 기록 6개와 의미가 겹치는 등급은 제거한다. 가장 큰 숫자는 생존 시간, 두 번째는 획득 성과 포인트다.
- 다음 행동은 `영구 연구`와 `다시 도전` 두 개만 버튼으로 표시하고 로비 이동은 ESC 안내로 낮춘다.
- 960×540, 1280×720, 1920×1080에서 버튼과 텍스트가 화면 안에 유지되어야 한다.
- 진입 종료에는 `작전 개시`, `전투 시작`, `작업 시작` 문구를 띄우지 않는다.

## 영구 연구

- 좌측 캐릭터 설명판, 미니맵, 같은 설명을 반복하는 하단 정보판을 제거한다.
- 선택한 노드의 이름·실제 효과·현재 단계·구매 비용은 트리 바로 위 한 영역에 표시한다.
- 흡연자 트리는 중앙 루트에서 기존 상·하·좌·우 1차 강화가 뻗고, 기존 방향의 2차 강화는 같은 방향으로 이어진다. 꽁초의 착지 즉시 타격 반응은 기본 동작이므로 연구 노드로 표시하지 않는다.
- 활성 연구는 한 장의 통합 연구망에 모두 남긴다. 노드 총개수는 줄이지 않으며 `담배·착화 / 도끼 / 폭죽 / 화염방사기 / 동료 / 설비 / 현장 운영`으로 분류한다. 명시된 선행조건을 만족한 노드가 한 카테고리에서 5개를 넘으면 기존 작성 순서의 앞선 5개만 구매 가능하고, 하나를 완료하면 다음 노드가 그 자리를 이어받는다. 전역 구매 가능 개수는 제한하지 않는다.
- 실제 보드 좌표도 중앙 `첫 불씨 단축` 통합 루트에서 일곱 카테고리 허브가 방사형으로 뻗고, 각 허브 바깥쪽에 해당 카테고리 노드만 계층형으로 전진하도록 배치한다. 카테고리 사이 공간을 넓게 비우고 전체 조망에서는 허브명만, 확대했을 때 개별 노드명을 표시한다. 다른 카테고리를 가로지르는 장거리 선은 그리지 않는다.
- 구매 완료·구매 가능 경로는 초록, 잠긴 경로는 회색으로 구분한다. 구조선에 붉은색을 쓰지 않는다.
- 연구 화면은 참고 UI와 같은 밝은 회백색 작업면과 옅은 비네트·먼지점만 사용한다. 숲 사진과 게임 월드 배경은 표시하지 않는다.
