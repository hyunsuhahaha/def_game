# 미채택 그래픽 시안 보관소

게임 런타임에서 사용하지 않지만 이후 다른 캐릭터·보스·지역에 재활용할 수 있는 시안을 보관한다.

## 규칙

- 현재 런타임 자산은 이 폴더로 옮기지 않는다.
- 미채택 시안은 삭제하거나 기존 파일을 덮어쓰지 않고 대상별 하위 폴더에 둔다.
- 파일명에는 대상, 상태, 버전을 적는다. 예: `worldtree-siege-rejected-v2.png`.
- 런타임 카탈로그와 빌더는 이 폴더의 이미지를 입력으로 사용하지 않는다.
- 시안을 다시 채택할 때는 새 버전의 제작 자산으로 복사한 뒤 그래픽 검증 절차를 다시 수행한다.

## 현재 보관 항목

### `worldtree/`

- `worldtree-siege-rejected-v1.png`: 뿌리가 과도하고 중앙이 마법 제단처럼 보여 미채택.
- `worldtree-siege-rejected-v2.png`: 자연 거목 방향의 두 번째 검토안. 최종 세계수 디자인으로 채택되지 않음.
