# 현재 적용본: arcade v3 / 이전 미채택 시안 보존

`arcade/*-atlas-v3.png`와 `src/forest_arcade_catalog.lua`는 승인된 숲 방향으로 새로 제작해 런타임에 연결한 자산이다. 고정 모델은 `concepts/forest-arcade-models-v3.png`이며, 아래 미채택 원화와 다르다. [규격·검증](../../docs/FOREST_ARCADE_ART.md)을 확인한다.

## 미채택 v1/v2 — 런타임 연결 금지

이 폴더의 `forest-enemies-concept-v1.png`, `forest-enemies-indie-concept-v2.png`와 그로부터 파생한 `ingame/*-atlas-pixel-v1.png`는 사용자에게 방향이 맞지 않는다고 평가받은 실험 시안이다. 파일은 보존하지만 **승인된 최종 자산이 아니며 게임에 연결하지 않는다.** `src/forest_enemy_catalog.lua`와 제작 스크립트 역시 이 실험의 산출물이다.

최신 사용자 방향은 **뱀파이어 서바이버즈 느낌에 조금 더 나은 픽셀 품질과 역동성**이다. 기존 몬스터의 단순한 비율·정체성을 유지하고, 나무의 사실적인 묘사를 줄여 카툰 픽셀 형태로 맞춘다. 복잡한 판타지 크리처나 장식적인 귀여운 캐릭터 전면 재디자인은 채택하지 않는다.

현재 화면 시안과 승인 상태는 [`FOREST_STYLE_STUDY.md`](../../docs/FOREST_STYLE_STUDY.md)를 확인한다.
