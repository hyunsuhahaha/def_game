# LAST HAUL

공용 보조 스킬 8종에 전용 픽셀 스프라이트·날갯짓·가시 덩굴·왕복 잔상·씨앗 폭발·연쇄 전류·포자 구름을 적용했습니다. [표현·판정·제작 규격·검증](docs/SUPPLEMENT_FX.md), [움직임 비교](docs/previews/supplement-fx-v1.gif)를 확인하세요.

맵별 전용 보스는 [고목왕·악어왕·바오밥 폭군·소라게 디자인](docs/BIOME_BOSSES.md)을 준비했습니다. 외형과 공격 패턴 시안이며 전용 보스 AI는 아직 인게임 미연결입니다.

캐릭터 선택 뒤 **온대 숲·맹그로브·마다가스카르·무인도**를 고를 수 있습니다. 새 지역은 서로 다른 나무 3종씩 섞이고, 늪지 악어·화난 여우원숭이·해변 게가 전투에 등장합니다. [맵 구현·조망·검증](docs/CLEARCUT_MAPS.md), [생태 조사와 적용 범위](docs/BIOME_ECOLOGY.md), [혼합 식생 기준](docs/BIOME_VEGETATION.md)을 확인하세요.

숲에는 바위·수풀·낙엽·쓰러진 통나무와 구역별 배치를 추가했습니다. [적용 범위·실제 코드 미리보기·제작 프롬프트](docs/FOREST_SCENERY.md)를 확인하세요.

벌목 모드 융합스킬은 재료 두 개를 모두 만렙으로 만들면 **확정 획득 카드**가 열립니다. [6종 조합·효과·검증](docs/CLEARCUT_FUSIONS.md)을 확인하세요.

숲 그래픽은 **뱀서 느낌의 카툰 픽셀 v3**를 적용했습니다. [제작 규격·적용 범위·검증 결과](docs/FOREST_ARCADE_ART.md), [실제 자산 오프스크린 렌더](docs/previews/forest-arcade-v3-runtime.png)를 확인하세요.

LÖVE 11.5 기반 2D 쿼터뷰 파밍 디펜스 프로토타입입니다. 플레이어는 직접 전투하지 않고 농사·벌목·채광으로 자원을 생산해 북쪽 전선을 방어합니다.

## 그래픽 제작 규칙

플레이어 캐릭터 애니메이션은 고정된 캐릭터 원화와 공통 발선을 바탕으로 제작하는 고밀도 픽셀 아틀라스를 사용합니다. 프레임별 독립 이미지 생성, 카테고리별 강제 색상 통일과 액션에서 분리된 타격 판정은 금지합니다. 전체 규격과 작업 절차는 [`docs/PIXEL_ART_PIPELINE.md`](docs/PIXEL_ART_PIPELINE.md)를 따릅니다.

## 개발 환경 준비

1. [LÖVE 공식 사이트](https://love2d.org/)에서 LÖVE 11.5를 설치합니다.
2. 저장소를 클론합니다.

```bash
git clone https://github.com/hyunsuhahaha/def_game.git
cd def_game
```

3. 프로젝트 루트에서 실행합니다.

```bash
love .
```

- Windows: `PLAY.bat` 더블클릭
- macOS/Linux: `./run.sh`
- 별도 Lua 설치는 필요하지 않습니다. LuaJIT은 LÖVE에 포함됩니다.

## 조작

- 로비 `Enter` 또는 `게임 시작`: 기존 15분 작전 모드
- 로비 `R` 또는 `채집 러시 실험실`: 기존 모드와 분리된 3분 벌목 폭주 프로토타입
- 채집 러시의 목표와 성공 지표: [`docs/RUSH_MODE_DESIGN.md`](docs/RUSH_MODE_DESIGN.md)
- 채집 러시 우측 상단 `실시간 전선 중계`: 숲을 캐는 동안 같은 월드의 북쪽 자동 전투와 방벽 상태 확인
- 채집 러시에서 마우스 왼쪽 버튼을 누른 채 이동: 도끼 범위 안의 가장 가까운 나무를 자동 타격
- 채집 러시 전용 벌목 월드: 모듈형 풀·흙 타일, 중앙 작업 공터, 전선 연결로, 자연형 숲 군락, 재생 대기 그루터기
- 채집 러시 숲은 산업 맵용 플레이어 조명을 사용하지 않으며 모든 나무를 항상 선명하게 표시
- `WASD` 또는 방향키: 이동
- 가까운 농지·나무·돌·광석을 왼쪽 클릭: 알맞은 도구 자동 사용
- 빈 농지 클릭: 나무 괭이로 씨앗 심기
- 심은 농지 클릭: 급수기로 물 주기
- 성장이 끝난 농지 클릭: 작물 수확
- `1`: 생체 수호자 생성
- `2`: 포탑 배치 모드 — 초록색 포대 슬롯을 클릭해 설치
- 설치한 포탑 근처에서 `F`: 광석을 사용해 포탑 강화 3택 열기
- 자동 포탑은 가장 가까운 적을 추적해 포신을 회전시키며, 쌍열 총구가 번갈아 실제 탄환을 발사합니다.
- 발사 시 고해상도 총구 화염·연기·불티·반동, 비행 궤적, 명중 섬광과 파편이 표시됩니다.
- `연쇄 코일`은 명중 적에서 주변 적으로 다층 전격이 튀며 추가 피해를 주고, `폭발 탄두`는 범위 피해와 화염·연기·충격파를 만듭니다.
- 채굴 드론의 하부 드릴은 상시 회전하며 생산 순간 가속되어 분진과 광석 파편을 뿜습니다.
- `3`: 작업 장비 강화
- `4`: 목재와 돌로 방어벽 강화
- 로비/결과 화면 `T`: 영구 특성 관제망
- 로비 또는 게임 중 `F10`: 테스트 옵션
- 방어벽 가까이에서 방벽 클릭: 수리 망치로 직접 수리
- 게임 중 `Escape`: 로비로 복귀
- 생산 레벨 상승 화면 `1/2/3` 또는 카드 클릭: 런 강화 선택

## 런 중 생산 시스템 빌드

채집과 웨이브 방어로 생산 경험치를 얻으면 게임이 일시 정지되고 무작위 강화 3개가 표시됩니다. 로비의 초기 보급은 시작 자원만 바꾸며 런의 테크를 제한하지 않습니다.

- 시스템 슬롯 6개: 자동 농기계, 채굴 드론, 벌목 로봇, 부화장, 레일 포탑, 수리소, 운반 드론, 전투 농장 등에서 자유롭게 선택
- 보조 슬롯 6개: 생산 속도, 가방, 이동 속도, 자원 복제, 사거리와 각 생산 계열 촉진제
- 보유 시스템을 다시 선택하면 최대 5단계까지 강화
- `자동 농기계 5단계 + 고단백 사료`처럼 주 시스템과 패시브 조건을 완성하면 최종 진화가 선택지에 등장
- 농업→병력, 채광→레일 포격, 벌목→톱날처럼 채집 결과가 전투 화면에 직접 연결

## 런과 영구 성장

한 런은 최대 15분이며 식량·광석·목재·돌과 런 중 업그레이드는 다음 런에 초기화됩니다. 런이 끝나면 생존 시간, 도달 웨이브, 처치 수, 채집량, 15분 생존 여부에 따라 영구 재화인 `유산 부품`을 획득합니다.

로비의 `영구 특성 관제망`에서 유산 부품을 사용합니다.

- 채집·운반: 채집 속도, 가방, 시작 씨앗, 이동 속도
- 방벽·수리: 방어벽 체력, 망치 수리량, 시작 자재, 피해 감소
- 자동 전선: 포탑 피해·공속, 시작 광석, 유산 부품 보너스
- 포대 확장: 기본 포대 슬롯은 1개이며, 강화할 때마다 방어벽 안쪽에 설치 슬롯이 1개씩 추가(최대 3개)

특성은 LÖVE 저장 폴더의 `meta_progress.sav`에 저장되어 게임을 종료해도 유지됩니다. 게임의 핵심을 지키기 위해 플레이어 직접 공격 특성은 넣지 않았습니다.

## 테스트 옵션

로비의 `테스트 옵션` 버튼이나 언제든 `F10`으로 개발용 메뉴를 엽니다.

- 연구 코인 `+1,000,000`: 현재 기록 모드의 영구 특성 구매 테스트용 재화를 즉시 저장
- 런 자원 각 `+1,000,000`: 식량·광석·목재·돌·씨앗 지급. 로비에서는 다음 런에 예약
- 생산 레벨 `+10`: 런 강화 3택을 연속 테스트. 로비에서는 다음 런에 예약
- 영구 재화·특성 초기화: 4초 안에 두 번 눌러 저장된 연구 코인과 영구 특성을 모두 초기화

## 구현 상태

- 한글 로비와 시작 빌드 선택
- 플레이어 추적 카메라와 Y축 정렬 쿼터뷰
- 하나로 연결된 전투·농장·숲·채석장·광산
- 15분 웨이브와 거점 자동 전투
- 파종 → 물주기 → 성장 → 수확 농사 순환
- 나무 도끼 자동 벌목
- 나무 곡괭이 자동 돌·광석 채집
- 도구 등급에 따른 채집 시간 변화
- 자원별 타격 흔들림·섬광·화면 진동·파편·효과음
- 채집 완료 자원 샤워·획득량 팝업·연속 채집 표시
- 4단계 외형과 체력을 가진 업그레이드 방어벽
- 적은 코어가 아니라 방어벽만 공격하며, 방어벽 붕괴 시 패배
- 채집을 중단하고 방어벽을 클릭해 목재·돌로 직접 수리
- 8프레임 걷기 및 도구별 작업 모션
- 자원 가방과 거점 자동 납품
- 런 종료 회수 보고서와 영구 재화 정산
- 저장되는 3계열 12종 영구 특성 트리
- 무작위 3택 방식의 20종 런 강화와 3종 최종 진화
- 6개 시스템·6개 보조 슬롯과 자유 조합 자동 생산/방어 빌드
- 새 전진 보급 센터와 실제 하드포인트 포탑 배치
- 전투 드론 독립 스프라이트와 부유·공격 표시
